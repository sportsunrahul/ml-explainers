The loopLabels are the scarce input

Two decisions in every feedback loop

Picture the platform from the model's side. Images arrive all day from cameras, the model scores each one, and a person can label only a few of them. Every label costs a person's time, and not every label comes back right.

So every round of the loop makes two decisions. The first is which images go to a person. The second is which of the returned labels the model should believe. Part one of this page is about the first decision, and part two is about the second.

Each decision has a naive default: send a random sample, and believe every label. The rest of the page is the case for and against doing better than those two defaults. The case is not one-sided. Random sampling turns out to be a much stronger default than its reputation (chapter 5). Believing every label turns out to be a much weaker one: a large network will learn any label you give it, wrong ones included (chapter 7), and even famous test sets carry label errors (chapter 8).

Before reading on, make a guess. If you could label only one image in a hundred, which one would you pick? Most people answer "the one the model is least sure about". The next chapter builds exactly that, and the three after it show where it breaks.
