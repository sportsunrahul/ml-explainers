# Sohn 2016: Multi-class N-pair loss

## 1. Identity
- Title: Improved Deep Metric Learning with Multi-class N-pair Loss Objective
- Venue: NIPS 2016 (30th NeurIPS, Barcelona; PDF footer). Non-arXiv; read sources/sohn2016/paper.pdf (9 pages).
- Author: Kihyuk Sohn (NEC Laboratories America).

## 2. Core problem
Contrastive and triplet losses converge slowly because each update sees only one negative.

## 3. Prior methods and why that hurt
Triplet loss "employ[s] only one negative example while not interacting with the other negative
classes per each update"; hard negative mining is expensive (Sec 1).

## 4. Key idea
Compare the anchor with its positive and N-1 negatives at once (a softmax-like loss), and build the
batch from N pairs of N different classes so each pair's positive serves as a negative for the other
anchors: 2N embeddings instead of (N+1)N.

## 5. Mechanism
1. Sample N pairs (x_i, x_i+) from N distinct classes.
2. Embed all 2N images.
3. For anchor x_i: positive x_i+, negatives x_j+ for j != i.
4. Loss Eq. 7, averaged over i. Optional symmetric version (footnote 2).
5. Instead of unit-norm features, an L2 penalty keeps embedding norms small (Sec 3.2.2).

## 6. Equations (PDF pp.3-4)
Eq. (3) (N+1)-tuplet loss:
```
\mathcal{L}(\{x, x^+, \{x_i\}_{i=1}^{N-1}\}; f) = \log\Big(1 + \sum_{i=1}^{N-1} \exp(f^\top f_i - f^\top f^+)\Big)
```
Eq. (6): the same as `-\log \frac{\exp(f^\top f^+)}{\exp(f^\top f^+) + \sum_{i=1}^{L-1}\exp(f^\top f_i)}` -- softmax cross-entropy form.
Eq. (7) multi-class N-pair loss:
```
\mathcal{L}_{N\text{-pair-mc}}(\{(x_i, x_i^+)\}_{i=1}^N; f) = \frac{1}{N}\sum_{i=1}^N \log\Big(1 + \sum_{j \neq i} \exp(f_i^\top f_j^+ - f_i^\top f_i^+)\Big)
```
- f_i: anchor embedding. f_i+: its positive. f_j+, j != i: other classes' positives used as negatives.
- Grades: an N x N anchor-by-positive score matrix; the diagonal is positive, off-diagonals negative.
- No temperature; no unit normalization (L2 regularization instead).
- N = 2 reduces to a smooth triplet loss (Eq. 4-5).

## 7. Setup
Adam; ImageNet-pretrained GoogLeNet init (except faces); 144 examples per batch = 72 pairs for Car-333 and Flower-610 (Sec 4.1).

## 8. Key number
Car-333 kNN recognition: 72-pair-mc 88.37 vs triplet 70.24 vs triplet-nm 83.22 (Table 1, Recognition row).

## 9. Limitations
Needs N distinct classes per batch (labels); hard negative class mining for large label sets.

## 10. Outline feedback
Tschannen (Sec 4) shows InfoNCE with a symmetric separable critic equals the N-pair-mc loss up to
constants. That is the cleanest bridge from ch-compare (margins) to ch-infonce (softmax). Consider
placing N-pair between FaceNet and InfoNCE in the bridge paragraph.
