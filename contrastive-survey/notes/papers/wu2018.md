# Wu 2018: Instance discrimination with a memory bank

## 1. Identity
- Title: Unsupervised Feature Learning via Non-Parametric Instance-level Discrimination
- arXiv 1805.01978, read v1 (2018-05-05, abs.html).
- Authors: Zhirong Wu ... Dahua Lin (Wu, Xiong, Yu, Lin).
- Venue: CVPR 2018 (cvpr.sty in source; venue not printed in arXiv text).
- Repo: http://github.com/zhirongw/lemniscate.pytorch (Sec 4.2).

## 2. Core problem
Learn a feature metric without labels that still puts visually similar images close.

## 3. Prior methods and why that hurt
- Parametric softmax with one weight vector w_j per class: w_j is a class prototype, "preventing
  explicit comparisons between instances", and does not generalize to new instances (Sec 3.1).
- Pretext tasks (context, colorization, jigsaw, split-brain): accuracy drops beyond conv3/conv4 and the
  best layers are >10,000-d (Sec 4.2, item 3-4).

## 4. Key idea
Treat every image as its own class; replace w_j^T v with v_j^T v on L2-normalized features, with
temperature tau, and keep all v_j in a memory bank; approximate the n-way softmax with NCE.

## 5. Mechanism
1. Backbone f_theta (AlexNet / VGG16 / ResNet-18 / ResNet-50) -> 128-d output, L2-normalized.
2. Memory bank V = {v_j}, one 128-d vector per training image (n = 1.28M for ImageNet), initialized as unit random vectors.
3. For image x_i, f_i = f_theta(x_i). Score against bank entries: exp(v_j^T f_i / tau).
4. NCE: positive = bank entry of the same instance i; m noise samples drawn uniformly (P_n = 1/n) from the bank.
5. Z treated as a constant, estimated by Monte Carlo from initial batches (Eq. 8).
6. Proximal term lambda ||v_i^(t) - v_i^(t-1)||^2 smooths training (Eq. 9-10).
7. After the step, write f_i into V at entry i ("f_i -> v_i").
8. Gradient flows only into theta through f_i; bank entries get no gradient (they are stored copies).
9. Test: weighted kNN, k=200, weights exp(s_i/tau), tau=0.07 (Sec 3.4).

## 6. Equations (approach.tex; macros \vv=\mathbf{v}, \vw=\mathbf{w}, \vf=\mathbf{f}, \vtheta=\boldsymbol{\theta} from mmstyle.sty)
Eq. (1) parametric softmax:
```
P(i | \vv) = \frac{\exp \left( \vw_i^T \vv \right)}{\sum_{j=1}^n \exp \left( \vw_j^T \vv \right)}.
```
Eq. (2), label `eqn:np_softmax`, non-parametric softmax (Sec 3.1):
```
P(i | \vv) = \frac{\exp \left( \vv_i^T \vv / \tau \right)}{\sum_{j=1}^n \exp \left( \vv_j^T \vv / \tau \right)},
```
"tau is a temperature parameter that controls the concentration level of the distribution".
v: current L2-normalized feature. v_i: stored feature of instance i (the positive). v_j, j != i: all
other instances (negatives). n: number of training images.

Eq. (3) objective: `J(\vtheta) =  - \sum_{i=1}^n \log P(i | f_{\vtheta}(x_i)).`

Eq. (4)-(5) NCE model and normalizer:
```
P(i | \vv) & = \frac{\exp(\vv^T \vf_i / \tau)}{Z_i}\\
Z_i = &\sum_{j=1}^n \exp \left( \vv_j^T \vf_i / \tau \right)
```
Eq. (6): `h(i, \vv) := P(D=1 | i, \vv) = \frac{P(i|\vv)}{P(i|\vv) + m P_n(i)}.`
Eq. (7) NCE loss:
```
J_{NCE}(\vtheta) =  - &E_{P_d} \left[\log h(i, \vv)\right] \notag\\
   - m \cdot & E_{P_n} \left[\log (1 - h(i, \vv')) \right].
```
"noise samples are m times more frequent than data samples"; v' = feature of another image drawn from P_n.
Eq. (8): `Z \simeq  Z_i \simeq n E_j\left[\exp(\vv_j^T \vf_i / \tau)\right] = \frac{n}{m} \sum_{k=1}^m \exp(\vv_{j_k}^T \vf_i /\tau),`
Eq. (9)-(10): proximal-regularized loss; lambda value NOT STATED.

## 8. Results
- ImageNet, ResNet-50, linear SVM on conv5 features: 54.0 top-1; kNN on 128-d output: 46.5 (Table 2, row Ours Resnet50).
- AlexNet conv5 SVM 35.6, kNN 31.3; ResNet-18 conv5 44.5, kNN 41.0 (Table 2).
- CIFAR-10 (ResNet-18, 128-d) kNN: non-param softmax 80.8, NCE m=4096 80.4, m=1 42.5, param softmax 63.0 (Table 1).
- Embedding size sweep ResNet-18 kNN: 32->34.0, 64->38.8, 128->41.0, 256->40.1 (Table 4).
- VOC07 detection ResNet-50 mAP 65.4 vs supervised 76.2 (Sec 4.4 text).
Protocol caution: the 54.0 is a linear SVM on conv5 features (Table 2 protocol 1), not a softmax probe
on the pooled output; CPC v2 Table 1 lists it as 54.0 "Instance Discr." for ResNet-50.

## 9. Limitations
- Bank entries are stale (written from older weights); proximal term only softens this. MoCo
  (1911.05722) replaces the bank with a momentum encoder and a queue.
- NCE approximation degrades for small m (Table 1).
