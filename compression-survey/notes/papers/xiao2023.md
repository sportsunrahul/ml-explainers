## 2. Core problem
W8A8 (INT8 weights and activations) would halve memory and use INT8 GEMM throughput, but LLM activations beyond 6.7B have systematic large outliers, so per-tensor or per-token activation INT8 destroys accuracy. LLM.int8() keeps accuracy by computing outliers in FP16, but "it is hard to implement the decomposition efficiently on hardware accelerators" (Sec 1).

## 3. What prior methods did and why that hurt (per the paper)
- Naive W8A8 (per-tensor dynamic): OPT-175B average 35.5 vs 66.9 FP16, WikiText 93080 (Table 3).
- ZeroQuant (group-wise weights, per-token dynamic activations): fine on GPT-3-350M and GPT-J-6B, fails on OPT-175B (35.8 avg).
- LLM.int8() (per-channel weights, per-token dynamic + FP16 outliers): accurate, but slower than FP16 in most cases (Table 11, Fig 8).
- Outlier Suppression (per-tensor static, non-scaling LayerNorm, token-wise clipping): works on BERT/BART, fails on LLMs (36.0 avg on OPT-175B).
- Per-channel activation quantization would fix accuracy (Table 1) but does not map to INT8 GEMM kernels: scales are allowed only on outer dims (tokens T, output channels C_o), not on the inner dim C_i (Sec 3, Eq 2, Fig 3).

## 4. The one key idea
Outliers sit in fixed input channels across all tokens, so divide each input channel j of X by s_j and multiply row j of W by s_j. The product is unchanged, activations become flat, and weights absorb part of the range; s_j is set offline from calibration data and folded into the previous layer.

## 5. Mechanism, step by step
1. Calibrate once: run 512 random Pile sentences, record per-input-channel max|X_j| for each linear layer input (Sec 5.1).
2. Per channel j, compute s_j = max|X_j|^alpha / max|W_j|^(1-alpha) (Eq 4); alpha = 0.5 default.
3. Fold diag(s)^-1 into the producer of X offline (LayerNorm affine params or previous linear layer); for residual-add inputs, add a scaling on the residual branch (Sec 4).
4. Replace W by diag(s) W offline (Eq 3).
5. Quantize: weights per-tensor INT8 (O1-O3); activations per-token dynamic (O1), per-tensor dynamic (O2), or per-tensor static with calibrated steps (O3) (Table 2).
6. Run all linear layers and attention BMMs (QK^T, PV) as INT8 CUTLASS GEMMs; keep ReLU, Softmax, LayerNorm in FP16 (Fig 6, Sec 4 last para).
Smoothing is applied to the inputs of self-attention and feed-forward layers (Sec 4).

## 6. Equations (TeX verbatim from src/text/3_motivation_method.tex)
No custom macros in the equations (macro.tex only defines \method etc.).

**Quantizer (Eq 1, Sec 2, p2)**
```
\bar{\mathbf{X}}^{\text{INT8}} =  \lceil\frac{\mathbf{X^{\text{FP16}}}}{\Delta}\rfloor, \quad \Delta=\frac{\max(|\mathbf{X}|)}{2^{N-1}-1},
```
Paper: integer uniform symmetric quantization; uses the max absolute value "so that it preserves the outliers". Gloss: X = FP16 tensor; X-bar = INT8 counterpart; Delta = step size; ceil/floor bracket = round; N = bits (8, so 2^{N-1}-1 = 127). Static = Delta from calibration samples; dynamic = Delta from runtime statistics.

**Effective levels (inline, Sec 3 observation 2, p3)**
`2^8 \cdot m_i/m` -- m_i = max magnitude of channel i, m = max of whole matrix. For non-outlier channels this is "very small (2-3)".

**Outer-dimension scaling (Eq 2, Sec 3, p3)**
```
\mathbf{Y} = \text{diag}(\mathbf{\Delta}_{\mathbf{X}}^{\text{FP16}}) \cdot (\mathbf{\bar{X}}^{\text{INT8}}\cdot \mathbf{\bar{W}}^{\text{INT8}}) \cdot \text{diag}(\mathbf{\Delta}_{\mathbf{W}}^{\text{FP16}})
```
Paper: in GEMM kernels "scaling can only be performed along the outer dimensions". Gloss: Delta_X = per-token step sizes (length T); Delta_W = per-output-channel step sizes (length C_o); both applied after the INT8 matmul. A per-input-channel scale would sit inside the sum and cannot be factored out.

**Smoothing transform (Eq 3, Sec 4, p4)**
```
\mathbf{Y} = (\mathbf{X}\text{diag}(\mathbf{s})^{-1}) \cdot(\text{diag}(\mathbf{s})\mathbf{W}) = \hat{\mathbf{X}} \hat{\mathbf{W}}
```
Paper: "smooth the input activation by dividing it by a per-channel smoothing factor s in R^{C_i}. To keep the mathematical equivalence ... we scale the weights accordingly in the reversed direction". Gloss: X in R^{T x C_i}; W in R^{C_i x C_o}; s = one positive scale per input channel; X-hat = smoothed activations; W-hat = rescaled weights.

**Migration strength (Eq 4, label eq:s_sqrt, Sec 4, p4)**
```
\mathbf{s}_j =  \max(|\mathbf{X}_j|)^{\alpha} / \max(|\mathbf{W}_j|) ^{1-\alpha}
```
Paper: "a hyper-parameter, migration strength alpha, to control how much difficulty we want to migrate from activation to weights"; with alpha = 0.5, "weights and activations at the corresponding channel share a similar maximum value". Gloss: j = input channel; max|X_j| = calibrated max of activation column j; max|W_j| = max of weight row j (the weights that multiply input channel j; Fig 5 takes abs max along W rows); alpha = 1 gives s_j = max|X_j| (all difficulty to weights); alpha = 0 gives s_j = 1/max|W_j| (all to activations).

Worked example (Fig 5, p4, alpha = 0.5): X = [[1, -16, 2, 6], [-2, 8, -1, -9]], channel abs max (2, 16, 2, 9); W (4x3) = [[2, 1, -2], [1, -1, -1], [2, -1, -2], [-1, -1, 1]], row abs max (2, 1, 2, 1); s = sqrt(max|X| / max|W|) = (1, 4, 1, 3); X-hat = [[1, -4, 2, 2], [-2, 2, -1, -3]] with channel max (2, 4, 2, 3) (the dashed box (1, 4, 1, 3) under X-hat is s, per its label); W-hat = [[2, 1, -2], [4, -4, -4], [2, -1, -2], [-3, -3, 3]]. Good seed for the toy's readout check.

## 8. Results worth remembering
Observations (Sec 3, p3; Fig 4, p4):
- "The scale of outliers in activations is ~100x larger than most of the activation values."
- Per-tensor INT8 leaves non-outlier channels "very small (2-3)" effective levels.
- "If one channel has an outlier, it persistently appears in all tokens"; variance across channels is large, variance within a channel across tokens is small.
- Fig 4 caption: OPT-13B linear layer; "a few channels ... whose magnitudes are very large (greater than 70)"; "the variance in one activation channel is small"; "the original weight distribution is flat and uniform".

- Three tall ridges, each spanning the full token axis: two dark red (one near the low-channel end, ~500, one near the high end, ~4800-5000) rising past the 70 tick; one lighter orange/salmon ridge near channel ~2000 (color suggests lower magnitude, height not readable across the break). ## 9. Limitations the paper states
- No explicit limitations section. Stated weak points: O3 static loses 0.8 (BLOOM) and 1.0 (GLM) average points; alpha must be found per model by grid search (0.5 to 0.9 across Tables 6-7); GLM needs top-2% token clipping.
- Weight-only methods (GPTQ) not compared directly; GPTQ's kernel then supported only batch-1 generation (App A). W4A4 left as future work.
- Fixed later (from given sources): AWQ (2306.00978) reuses per-channel activation-aware scaling for 4-bit weight-only quantization; GPTQ (2210.17323) handles 3-4 bit weights. Both are in ch-gptq-awq.
- Our reading: the scale-transfer algebra is the same as cross-layer equalization (Nagel 2019), which SmoothQuant cites in Related Work as unable to fix activation outliers. Good callback to viz-cle.
