## 2. Core problem
On-device LLM decoding at batch 1 is memory-bound, so 4-bit (and 3-bit) weight-only quantization (W4A16) should
speed it up. Round-to-nearest loses accuracy at low bits, and GPTQ's reconstruction "may overfit the calibration
set" (Sec. 1). The goal is an accurate low-bit weight quantizer that stays hardware-friendly and does not depend on
the calibration domain.

## 3. What prior methods did and why that hurt
- RTN: rounds each weight; "quite strong when using a small group size like 128" (Sec. 5.1) but degrades at INT3
  (Table 1 RTN column, Table 4).
- GPTQ: second-order error compensation (reconstruction). Per AWQ: overfits the calibration set, distorting
  out-of-distribution features (Fig. 8b), and needs a reorder trick for LLaMA-7B and OPT-66B (Sec. 2).
- Mixed precision (keep salient weights in FP16): accurate (Table 1) but "such a mixed-precision data type will
  make the system implementation difficult" (Sec. 3.1, Limitations).
- QAT: too expensive to train at LLM scale (Sec. 1, Sec. 2).

## 4. The one key idea
About 0.1%-1% of weight channels are salient, and they are the input channels that see large activations, not the
channels with large weights. Scale those input channels of W up by s > 1 (and the activations down by 1/s, fused
into the previous op) before quantizing; this shrinks their relative rounding error with no mixed precision. The
per-channel scale is s = s_X^alpha with one exponent alpha found by grid search.

## 5. Mechanism, step by step
1. Run a small calibration set from the Pile through the model; cache each linear layer's input features X (Sec.
   3.2 "Searching to scale"; Sec. 5.1).
2. Per input channel, compute s_X = "the average magnitude of activation (per-channel)" (Eq. 5 gloss).
3. For each alpha on a grid of 20 points over [0, 1] (Sec. 5.1 "grid size of 20"; Sec. 3.2 "[0, 1]"):
   s = s_X^alpha; quantize W diag(s) with the group quantizer (INT3/INT4, group size 128); compute
   L(s) = || Q(W diag(s)) (diag(s)^-1 X) - W X || (Eq. 4).
4. Keep alpha* = argmin L (Eq. 5). alpha = 0 means no scaling; alpha = 1 is "the most aggressive scaling in our
   search space" (Sec. 3.2).
5. Fold diag(s)^-1 into the previous operator ("it can usually be fused into the previous operator", Sec. 3.2),
   store Q(W diag(s)) as INT4 + FP16 group scales.
6. "We further apply weight clipping to minimize the MSE error of quantization" (Sec. 3.2). The paper gives no
   clipping procedure or grid. Toy should omit it or label it "not specified in the paper".
7. Inference (TinyChat, Sec. 4.2): dequantize INT4 -> FP16 on the fly inside the matmul kernel (MM and MV), pack
   weights for SIMD/GPU, fuse kernels. No backprop or regression anywhere.

Traps for the `viz-awq` toy (our reading):
- The analysis quantizer (Eq. 1) is symmetric max-abs per group: Delta = max|w| / 2^(N-1), Q(w) = Delta *
  Round(w / Delta), written with no clamp. As printed, max|w| maps to integer 2^(N-1) (e.g. 8 for N = 4), one level
  outside the signed INT-N range [-8, 7]. Pick a convention (e.g. divide by 2^(N-1) - 1, or clamp) and state it.
  The paper does not say whether its experiments use a zero point.
- Scaling is per INPUT channel of W (columns of W in Y = W X). Fig. 2 draws W with input channels as rows; the
  equation form is W diag(s).
- s_X is the mean of |X| per channel over calibration tokens, not the max (contrast SmoothQuant's max).
- Grid of 20 points over [0, 1]: exact spacing not printed (our reading: alpha = i/20, i = 0..19 or similar).
- No normalization of s is printed. Readout: L(s) as in Eq. 4 (no norm subscript in the paper; use Frobenius/MSE
  and say so).
- Shape facts for toy data (Table 2, OPT-6.7B, 1% salient channels scaled by s): share of groups whose Delta
  changes 0% / 2.8% / 4.4% / 8.2% / 21.2% at s = 1 / 1.25 / 1.5 / 2 / 4; average Delta'/Delta 1 / 1.005 / 1.013 /
  1.038 / 1.213; salient-channel error ratio (Delta'/Delta)(1/s) 1 / 0.804 / 0.676 / 0.519 / 0.303; PPL 23.54 /
  12.87 / 12.48 / 11.92 / 12.36. The toy should reproduce the U shape: salient error falls with s, but past some
  s the group max grows and non-salient error rises.

## 6. Equations (from `src/text/3_approach.tex`)
Eq. 1 (`eq:org_quant`, PDF Eq. 1):
```
Q(\mathbf{w}) = \Delta \cdot \text{Round}(\frac{\mathbf{w}}{\Delta}), \quad \Delta = \frac{\max(|\mathbf{w}|)}{2^{N-1}},
```
Paper: "N is the number of quantization bits, and Delta is the quantization scaler determined by the absolute
maximum value." Gloss: w = one group (block) of weights; Round = nearest integer.

Eq. 2 (`eq:scaled_quant`, PDF Eq. 2):
```
Q(w\cdot s)\cdot \frac{x}{s} = \Delta^{'} \cdot \text{Round}(\frac{ws}{\Delta^{'}}) \cdot x \cdot \frac{1}{s},
```
Paper: "Delta' is the new quantization scaler after applying s". Gloss: scale one weight w up by s, the matching
input x down by s; output is unchanged before rounding.

Eq. 3 (unlabelled, PDF Eq. 3):
```
\texttt{Err}(Q(w) x) &= \Delta\cdot \texttt{RoundErr}(\frac{w}{\Delta})\cdot x \\
\texttt{Err}(Q(w \cdot s)(\frac{x}{s})) &= \Delta^{'}\cdot \texttt{RoundErr}(\frac{ws}{\Delta^{'}})\cdot x\cdot \frac{1}{s}
```
Paper's three empirical assumptions: (1) RoundErr is roughly uniform on [0, 0.5], average 0.25, unchanged by
scaling; (2) scaling one element usually does not change the group max, so Delta' ~ Delta; (3) Delta and x are
FP16, no error. Hence "The ratio of the new error to the original error is (Delta'/Delta) * (1/s). Given Delta' ~
Delta and s > 1, the relative error is smaller for the salient weight w."

Eq. 4 (unlabelled, PDF Eq. 4):
```
\mathbf{s}^* &= \mathop{\arg\min}_{\mathbf{s}} \mathcal{L}(\mathbf{s}) \\
\mathcal{L}(\mathbf{s}) = \lVert Q(\mathbf{W}\cdot \text{di}&\text{ag}(\mathbf{s}))  (\mathbf{\text{diag}(s)^{-1}} \cdot \mathbf{X}) - \mathbf{W}\mathbf{X}  \rVert
```
(Rendering note: the source splits `diag` with an align `&` (`\text{di}&\text{ag}`); join it when rendering.)
Paper: "Q means the weight quantization function (e.g., INT3/INT4 quantization with group size 128), W is the
original weights in FP16, and X is the input features cached from a small calibration set ... s is a per-(input)
channel scaling factor". Q is not differentiable, and STE-style gradients "still suffer from unstable convergence",
hence the search space below.

Eq. 5 (`eq:scale_search_formula`, PDF Eq. 5):
```
\mathbf{s}=\mathbf{s_X}^{\alpha}, \quad \alpha^*=\mathop{\arg\min}_{\alpha}\mathcal{L}(\mathbf{s_X}^{\alpha})
```
Paper: "s_X is the average magnitude of activation (per-channel), and we use a single hyper-parameter alpha to
balance between the protection of salient and non-salient channels."

## 9. Limitations stated
- The paper has no limitations section. Stated caveats: mixed precision is hardware-unfriendly (Sec. 3.1); very
  large s hurts non-salient channels (Table 2); OpenFlamingo quantizes only the language part (Sec. 5.2).
- Internal inconsistencies to keep out of claims:
  - Fig. 2 caption: OPT-6.7B INT3-g128 RTN PPL 43.2 -> keep 1% FP16 13.0 -> AWQ 13.0. Tables 1 and 3 give 23.54 ->
    11.39 -> 11.39 for the same stated setup. Use the tables.
  - RTN OPT-1.3B INT3-g128: 119.00 (Table 1) vs 119.47 (Table 3).
  - Llama-2-13B on RTX 4070: "30 tokens/second" (Sec. 1) vs "33 tokens/s" (Sec. 5.4, Fig. 9c).
  - The tex gives label `tab:opt_ppl` to both Table 3 and Table 5, so the PDF text says "Table 5" for the OPT
    ablation; the content is Table 3.
