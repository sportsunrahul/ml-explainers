Fake quantization

Rounding a value onto the integer grid and immediately scaling it back to a float: divide by the step size, clip to the grid's range, round to the nearest integer, multiply by the step size again. The result is still a float tensor, but every value sits exactly on a grid level, so the forward pass sees the same numbers the integer model will compute.

Shadow weights

The full-precision (FP32) copy of each weight that the optimizer updates during quantization-aware training. Each forward pass rounds the shadow weights onto the grid and uses only the rounded values. Small updates add up in the shadow weight until it crosses a rounding boundary and the rounded value jumps to the next level. After training, only the rounded integers are kept.

Gradient

For each weight, how much the loss would change if that weight moved a little, and in which direction. Training moves every weight a small step against its gradient. Backpropagation computes the gradient from the loss back to the input by multiplying the slopes of every operation on the way. One flat operation, with slope zero, stops the gradient for everything before it.

Straight-through estimator

A rule for the backward pass through rounding: use slope 1, as if rounding did nothing, instead of its true slope of zero. Bengio, Leonard and Courville named it for binary neurons, crediting a lecture by Hinton. Quantization uses a clipped version: slope 1 inside the grid's range and 0 outside it (Krishnamoorthi; Esser et al.; Wu et al.). The estimate is biased, but in practice it trains.
