Attention, all the way down

How the Transformer works, how a large language model turns it into a text generator, and the engineering (caches, kernels, experts, quantisation and adapters) that makes it affordable to train and run.

1

What a language model does

A large language model (LLM) does one thing: given a sequence of tokens, it outputs a probability distribution over the next token. Generating text is just repeating that: pick a token, append it, predict again. Everything interesting (answering questions, writing code, reasoning) emerges from doing this one prediction extremely well after training on trillions of tokens.

The network that makes the prediction is almost always a decoder-only Transformer. The original Transformer (Vaswani et al., 2017) was an encoder–decoder for translation; GPT kept only the decoder half, with a mask so each position can only look backwards. That design, scaled from GPT-2 (1.5B parameters, 2019) to GPT-3 (175B, 2020) and beyond, is the basis of nearly every modern LLM.

2

Tokenisation

Models don't read characters or words; they read tokens, chunks from a fixed vocabulary. Characters make sequences too long; whole words can't handle new words or typos. The standard compromise is byte-pair encoding (BPE, Sennrich et al., 2016): start from single characters (or bytes), repeatedly find the most frequent adjacent pair in the training corpus, and merge it into a new token. Frequent words become single tokens; rare words split into familiar pieces. GPT-2 used about 50,000 tokens; Llama 3 uses about 128,000.

Below, a real BPE tokenizer is trained live in your browser on a short paragraph about machine learning. Increase the number of merges and watch common words fuse into single tokens. A leading ▁ marks a space, as in SentencePiece.

3

Attention

Each token starts as a learned embedding vector. Attention is how tokens exchange information. Every token produces three vectors through learned linear maps: a query (what am I looking for?), a key (what do I contain?) and a value (what will I pass on?). Each token compares its query to every key, turns the scores into weights with a softmax, and takes the weighted average of the values.

Attention(Q, K, V) = softmax( Q Kᵀ / √dk + M ) V dk is the key dimension; dividing by √dk keeps the scores from growing with dimension and saturating the softmax. M is the causal mask: −∞ above the diagonal, so token i can only attend to tokens 1…i. Without it (as in BERT-style encoders), attention is bidirectional.

Multi-head attention runs several attentions in parallel with separate projections (for example 32 heads of dimension 128 in a 4096-wide model), concatenates the results and projects back. Different heads learn different jobs. Some famous ones: previous-token heads, induction heads that copy patterns seen earlier in the context, and heads that resolve pronouns.

4

The Transformer block

A model is a stack of identical blocks (32 in Llama 3 8B, 126 in Llama 3 405B). The key idea is the residual stream: a vector per token that flows through the whole network, and each block adds something to it rather than replacing it.

h = x + Attention( Norm(x) )    →    out = h + MLP( Norm(h) ) This is the “pre-norm” arrangement used by modern models; the original put the norm after the addition, which is harder to train deep. RMSNorm (rescaling by the root-mean-square, no mean subtraction) has largely replaced LayerNorm.

The MLP (feed-forward network) is applied to each token independently: expand to about 4× the width, apply a non-linearity, project back. Modern models use a gated variant, SwiGLU: SiLU(xW₁) ⊙ (xW₃) · W₂. Attention moves information between tokens; the MLP processes it within each token and holds much of the model's stored knowledge. Roughly two-thirds of the parameters live in MLPs. A useful rule of thumb: a model with L layers and width d has about 12·L·d² parameters.

At the end, a final norm and a linear “unembedding” map the last residual vector to one logit per vocabulary token, and a softmax turns those into next-token probabilities.

5

Positional encodings

Attention by itself ignores order: shuffle the tokens and each output is unchanged apart from being shuffled too. Position must be injected. The original paper added fixed sinusoidal vectors to the embeddings; GPT-2 learned one vector per position. Both tie the model to the lengths it was trained on.

RoPE (rotary position embedding, Su et al., 2021), now standard, rotates the query and key vectors instead. Split each vector into pairs of dimensions; rotate pair i by an angle proportional to position m and a frequency θi = base−2i/d. Because rotations compose, the dot product between a query at position m and a key at position n depends only on m − n. Relative position comes for free.

⟨ R(mθ) q, R(nθ) k ⟩ = ⟨ q, R((n − m)θ) k ⟩ Low-index pairs spin fast and track fine, local order; high-index pairs spin slowly and track long-range position. Context-extension tricks such as position interpolation and YaRN rescale these frequencies so a model trained on 8k tokens can handle 128k.
6

Training and generation

Pretraining uses plain cross-entropy on the next token at every position at once. Thanks to the causal mask, one forward pass over a 4,096-token sequence gives 4,096 training examples. This is called teacher forcing: the model always sees the true previous tokens during training.

L = − (1/T) Σt log pθ( xt | x<t )

Generation turns the predicted distribution into a choice. Greedy decoding takes the top token and tends to loop. Temperature divides logits by T before the softmax: T < 1 sharpens, T > 1 flattens. Top-k keeps the k most likely tokens; top-p (nucleus) sampling keeps the smallest set whose probabilities sum to p. Generation has two phases with different costs: prefill processes the whole prompt in parallel and is compute-bound; decode produces one token at a time and is limited by memory bandwidth. That asymmetry is why the next section matters.

7

The KV cache

When generating token t, attention needs the keys and values of all earlier tokens. They never change, because causal masking means earlier tokens never see later ones. So instead of recomputing them every step, the model stores them: the KV cache. Each step then only computes the new token's query, key and value. This turns generation from quadratic to linear in work, at the cost of memory that grows with context length.

KV memory = 2 × layers × KV heads × head dim × tokens × bytes per value The 2 is for keys and values. For a Llama-3-8B-sized model (32 layers, 8 KV heads of dimension 128, 16-bit) that is 128 KiB per token, or 1 GiB for an 8,192-token context, per sequence.

To shrink the cache, multi-query attention (MQA, Shazeer 2019) shares one key/value head across all query heads, and grouped-query attention (GQA, Ainslie et al., 2023) shares each key/value head across a group. PagedAttention (vLLM) stores the cache in fixed-size pages, like virtual memory, so many requests can share a GPU efficiently.

8

Scaling laws

Kaplan et al. (2020) found that loss falls as a smooth power law in model size N, data size D and compute C, over many orders of magnitude. Training compute is roughly C ≈ 6ND floating-point operations. Hoffmann et al. (Chinchilla, 2022) redid the analysis more carefully and concluded that for a fixed compute budget, parameters and tokens should grow in roughly equal proportion, about 20 training tokens per parameter. Their 70B Chinchilla, trained on 1.4T tokens, beat the 280B Gopher trained with the same compute.

L(N, D) = E + A / Nα + B / Dβ    with E = 1.69, A = 406.4, B = 410.7, α = 0.34, β = 0.28 E is the irreducible loss (the entropy of text); the other terms are the penalties for a finite model and finite data. The constants are Chinchilla's parametric fit.

In practice, models are now often trained far beyond the compute-optimal point (Llama 3 8B saw about 15T tokens, nearly 1,900 per parameter), because a smaller model trained longer is cheaper to serve. Scaling laws have since been extended to inference-time compute, which the post-training guide covers.

9

Efficient training and inference

FlashAttention: the same maths, less memory traffic

Standard attention writes the full N × N score matrix to GPU main memory (HBM), reads it back for the softmax, writes it again, and reads it once more to multiply by V. For long sequences this memory traffic, not arithmetic, is the bottleneck. FlashAttention (Dao et al., 2022) computes attention in tiles that fit in fast on-chip memory (SRAM), using an “online softmax” that keeps a running maximum and sum so blocks can be combined exactly. The N × N matrix is never stored. Results are identical, memory drops from quadratic to linear in N, and speed improves several times. FlashAttention-2 and -3 improved parallelism and use newer GPU features.

Mixture of experts

A mixture-of-experts (MoE) layer replaces the single MLP with many expert MLPs and a small router that sends each token to only the top-k of them (often k = 2). Total parameters grow, but compute per token stays close to that of one expert. Mixtral 8x7B has about 47B parameters but uses about 13B per token; DeepSeek-V3 has 671B with 37B active. The catch is balance: routers tend to favour a few experts, so training adds a load-balancing loss, and experts have a capacity limit beyond which tokens are dropped or overflow. All experts must also sit in memory, so MoE saves compute, not memory.

Quantisation

Weights are usually trained in 16-bit formats. Storing them in 8 or 4 bits halves or quarters memory and speeds up memory-bound decoding. The simplest scheme scales each group of weights so the largest fits the integer range and rounds. The difficulty is outliers: a few very large values in LLM activations and weights stretch the range and wreck precision for everything else. LLM.int8() handles outlier features separately; GPTQ uses second-order information to compensate rounding errors; AWQ protects the most important channels; small per-group scales (for example every 64 or 128 weights) contain the damage.

LoRA: fine-tuning with a tiny adapter

Full fine-tuning updates every weight and needs optimizer state for all of them. LoRA (Hu et al., 2021) freezes the pretrained weight W and learns a low-rank update ΔW = B·A, with B of size d × r and A of size r × d, where r is small (4 to 64). Only A and B are trained, which cut trainable parameters for GPT-3 by about 10,000×, and the update can be merged into W after training, so inference costs nothing extra. QLoRA (Dettmers et al., 2023) goes further: the frozen base is quantised to 4 bits (the NF4 format) and LoRA adapters are trained on top, letting a 65B model be fine-tuned on a single 48 GB GPU.

More tricks worth knowing

Speculative decoding lets a small draft model propose several tokens and the large model verify them in one pass, keeping the large model's output distribution exactly while generating faster. Parallelism spreads training across thousands of GPUs: data parallelism with sharded optimizer states (ZeRO, FSDP), tensor parallelism that splits each matrix (Megatron-LM), pipeline parallelism that splits the layers, and sequence or context parallelism for long inputs. Mixed precision (bf16, and increasingly fp8) speeds up the arithmetic, and continuous batching keeps GPUs busy when serving many users.

10

Strengths, limits and alternatives

Why Transformers won

  • Every position trains in parallel, unlike recurrent networks, so they use GPUs efficiently.
  • Any token can reach any other in one step, which makes long-range dependencies easy.
  • Performance scales smoothly and predictably with data and compute.
  • One architecture works for text, images, audio, video, proteins and actions.

Where they struggle

  • Attention cost grows with the square of sequence length, and the KV cache grows linearly.
  • Tokenisation causes odd failures with spelling, digits and non-English text.
  • Fixed-depth computation per token limits how much “thinking” fits in one step, which is why chain-of-thought helps.
  • They can state false things fluently; nothing in next-token training enforces truth.

Alternatives aim at the quadratic cost. State-space models such as Mamba (2023) and linear-attention variants keep a fixed-size state and scale linearly; hybrid models interleave a few attention layers with many such layers. They are competitive on many tasks, but pure attention still leads on precise recall over long contexts.
