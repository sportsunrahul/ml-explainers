# LLaVA (Visual Instruction Tuning) 2304.08485v2 -- chapter 7 extraction

Source: sources/llava/src/subtex/{approach,experiment,appendix}.tex. Paper says the LLM is Vicuna
(13B is the "best 13B model" in the ScienceQA ablation; 7B is only an ablation).

## Architecture (Sec. 4.1)
- Encoder: pre-trained CLIP visual encoder ViT-L/14 (Radford et al.), Z_v = g(X_v). "The grid
  features before and after the last Transformer layer are considered in our experiments."
  Used: the features BEFORE the last layer (ScienceQA ablation: last layer 89.96% vs before-last
  90.92%, -0.96). Their stated reason: last-layer features "may focus more on global and abstract
  image properties", the layer before "more on localized properties". No 224 / 256-token count is
  stated in the paper (ViT-L/14 at 224 px = 16x16 = 256 grid tokens is COMPUTED, not quoted).
- Connector: "a simple linear layer"; trainable projection matrix W maps Z_v to language embedding
  tokens H_v with the same dimension as the LLM word embeddings.

Eq. 1 (verbatim TeX, numbered (1)):
  H_v = W \cdot Z_v, \text{ with } Z_v = g(X_v)
  - X_v: input image; g: frozen CLIP ViT-L/14; Z_v: grid patch features; W: trainable projection
    matrix; H_v: sequence of visual tokens fed to the LLM alongside text embeddings.

Eq. 2 (numbered (2), how the instruction at turn t is assembled):
  X_instruct^t = { Randomly choose [X_q^1, X_v] or [X_v, X_q^1], for the first turn t=1 ;
                   X_q^t, for the remaining turns t>1 }
  (image is placed before or after the first question at random; later turns are text only.)

Sequence format (Table 2 of paper, "input sequence used to train the model"):
  X_system-message <STOP>
  Human: X_instruct^1 <STOP>  Assistant: X_a^1 <STOP>
  Human: X_instruct^2 <STOP>  Assistant: X_a^2 <STOP> ...
  Follows Vicuna-v0 system message; <STOP> = "###". Loss only on the assistant answers X_a and the
  <STOP> that ends them ("The model is trained to predict the assistant answers and where to stop").

Eq. 3 (numbered (3), training objective, verbatim TeX):
  p( X_a | X_v, X_instruct ) = \prod_{i=1}^{L} p_{\theta} ( x_i | X_v, X_{instruct,<i}, X_{a,<i} )
  - L: length of the answer sequence; x_i: i-th answer token (green = predicted/loss tokens);
    theta: trainable parameters; X_{instruct,<i}, X_{a,<i}: instruction and answer tokens of all
    turns before position i. X_v is written explicitly to stress the image is the grounding for all
    answers. System message and earlier <STOP> omitted for readability.

## GPT-4 data generation (Sec. 3)
- GPT-4 (and ChatGPT) is TEXT-ONLY. It never sees pixels. Image is encoded as two symbolic
  contexts: (i) Captions (COCO, several per image, different perspectives), (ii) Bounding boxes
  (object class + location, format e.g. "person: [0.681, 0.242, 0.774, 0.694]", normalized x1,y1,x2,y2).
- Images: COCO. For each of 3 types, a few examples were hand-written by the authors: "the only
  human annotations we have during data collection", used as in-context seed examples.
- Three response types:
  1. Conversation: multi-turn Q&A, answers in the tone of the assistant seeing the image; asks
     about object types, counting, actions, locations, relative positions; only questions with definite answers.
  2. Detailed description: one question randomly sampled from a curated list of "describe in detail"
     prompts (list generated by GPT-4 then curated; Appendix lists them).
  3. Complex reasoning: in-depth, step-by-step reasoning questions built on the content.
- Counts: 158K unique language-image samples = 58K conversations + 23K detailed description + 77K
  complex reasoning ("77k" in source). 58+23+77 = 158. ~80K unique images (Sec. 5 text: "~80K unique images").
- GPT-4 vs ChatGPT: ablated early; "GPT-4 consistently provides higher quality ... such as spatial reasoning."
- Naive baseline the paper rejects: Human: X_q X_v <STOP> Assistant: X_c <STOP> (caption as answer)
  -- "cheap ... but lacks diversity and in-depth reasoning".

## Training (Sec. 4.2, Sec. 5, Appendix "Training Details")
- Stage 1, feature alignment: CC3M filtered to 595K image-text pairs (noun-phrase filter: drop
  phrases with freq < 3; from lowest-frequency phrases add captions; cap 100 captions per phrase;
  "around 595K"). Converted to single-turn instruction data via the naive expansion (random
  "briefly describe the image" question, answer = original caption). Frozen: visual encoder AND LLM.
  Trainable: W only (theta = W). "training a compatible visual tokenizer for the frozen LLM".
  1 epoch, lr 2e-3, batch 128. Time: within 4 hours on 8x A100.
- Stage 2, end-to-end: visual encoder frozen; trainable = projection W AND LLM weights phi
  (theta = {W, phi}). Chatbot: LLaVA-Instruct-158K, 3 epochs, lr 2e-5, batch 32; within 10 hours.
  Conversation is multi-turn, other two single-turn; sampled uniformly.
  ScienceQA: 12 epochs (best), within 4 hours; single-turn: question+context = instruct,
  reasoning+answer = answer.
- Common: Adam, no weight decay, cosine schedule, warmup ratio 3%, FSDP + gradient checkpointing,
  BF16 + TF32, 8x A100 ("following Vicuna's hyperparameters").

## Headline numbers
- 85.1% relative score: LLaVA-Bench (COCO), full-data row (conv 83.1, detail 75.3, complex 96.5,
  all 85.1). "Relative" = GPT-4 judge score of LLaVA's answer divided by the score of text-only
  GPT-4's answer given the ground-truth captions+boxes as visual input (upper bound), 1-10 scale
  judged on helpfulness, relevance, accuracy, detail. LLaVA-Bench (COCO) = 30 COCO-val-2014 images
  x 3 question types = 90 questions. Abstract calls it "a synthetic multimodal instruction-following dataset".
- Data ablation (LLaVA-Bench COCO, All): full 85.1; detail+complex 81.9; conv+5% detail+10%
  complex 80.5; conversation only 73.8; no instruction tuning 21.5.
- LLaVA-Bench (In-the-Wild): 24 images, 60 questions. LLaVA 67.3 +- 2.0 (all), BLIP-2 38.1,
  OpenFlamingo 19.1.
- ScienceQA (test avg): LLaVA alone 90.92%; SoTA MM-CoT Large 91.68%; LLaVA + GPT-4 judge = 92.53%
  (new SoTA). 92.53% is NOT LLaVA alone: whenever GPT-4 (text-only) and LLaVA disagree, GPT-4 is
  asked again to give a final answer. Also a "GPT-4 complement" scheme exists (Table in Sec 5.2).
- ScienceQA ablations: last-layer features 89.96 (-0.96); no pre-training (from scratch) 85.81 (-5.11);
  7B 89.84 (-1.08); answer-first 12 epochs 89.77, reasoning-first reaches 89.77 in 6 epochs.

## Outline assertions I could not confirm or that are wrong
- Outline: "which CLIP layer (penultimate grid)". Paper says "the visual features before the last
  layer" / "before the last Transformer layer" (grid features). "Penultimate" is the reasonable gloss;
  the paper states it as an ablation on ScienceQA, not the main chat model.
- Outline: "ScienceQA 92.53%" and "85.1%" are fine but must be attributed: 85.1 = LLaVA-Bench (COCO)
  relative score; 92.53 = LLaVA + GPT-4 as judge ensemble (LLaVA alone 90.92).
- Outline: stage epochs/steps. Paper gives epochs and batch sizes only, no step counts (steps are
  derivable: 595K/128 ~ 4.65K steps; 158K/32 ~ 4.9K steps/epoch, ~14.8K for 3 epochs; COMPUTED, not stated).
- 256 visual tokens per image is not stated in the paper (computed from 224/14 = 16, 16^2 = 256).
- Boxes format in the example: normalized [x1,y1,x2,y2] floats in [0,1] (four numbers); the paper
  does not name the coordinate order explicitly.
