Visual prompt

A visual prompt is a box (or a point) drawn on an example image instead of a typed name. The detector reads the image features around the box and turns them into one vector, in the same space as its text vectors. That vector then scores every candidate box, exactly as a class name would. OWL-ViT did this with one example image; T-Rex2 trains names and boxes together so that their vectors line up.

In-context examples

An in-context example is a labelled example that you show the model at test time, without training it. The weights stay fixed, so papers often call the result zero-shot. But the model still sees labelled examples of the class, which a typed name does not need. So compare it with few-shot methods, which get the same examples, not with a plain name.

RF100-VL and nuImages

RF100-VL (Roboflow100 Vision-Language) collects 100 small detection datasets from domains such as industry, medicine and aerial images, chosen to hold concepts that are rare on the web. FSOD-VLM reuses nuImages, a driving dataset, as a few-shot test; its "Few" group holds the classes with the fewest examples. Both measure average precision (AP).
