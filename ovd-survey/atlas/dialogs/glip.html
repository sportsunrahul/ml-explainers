Phrase grounding

Phrase grounding takes an image and a caption and finds the box that each phrase of the caption refers to. In "a man walks a dog", it boxes the man and the dog. GLIP's insight is that detection is the same task: write the class names as a caption, "person. car. dog.", and ground each name. Detection data, grounding data and web captions with boxes can then train one model with one loss.

Tokens and subwords

A text encoder such as BERT does not read whole words. A tokenizer first cuts the text into tokens from a fixed vocabulary. Common words are one token; rare words become several subword pieces. The encoder also adds special tokens of its own, for example one at the start and one at the end. GLIP scores each box against each token, so a phrase of three tokens gets three scores, and GLIP averages them.

Cross-attention and deep fusion

In attention, each item computes a weighted average of other items, with weights from how well they match. In cross-attention, the items come from two different sources: here, image regions and text tokens. Each region reads from the tokens, and each token reads from the regions. GLIP puts this block before each of the last encoder layers, so the image features change with the prompt. Without it, text and image meet only in the final score; that design is called late fusion.
