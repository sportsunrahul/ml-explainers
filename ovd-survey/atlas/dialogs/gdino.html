DINO, the detector

DINO is a detector from the DETR family. A transformer encoder turns the image into tokens. A decoder holds a fixed set of queries, and each query outputs one box and one class. During training, a matching step pairs each real object with exactly one query, so the model needs no duplicate removal afterwards. DINO adds training tricks and starts each query's box at a location that the encoder scores highly. It shares its name with an unrelated self-supervised image model.

Cross-attention

Attention lets each token collect information from other tokens, weighted by how well they match. In cross-attention the two groups differ: image tokens collect from the text tokens, and text tokens collect from the image tokens. After a few such layers, an image token on a forklift carries some of the word "forklift", so the image features depend on the prompt.

Queries and anchor boxes

A query is one slot in the decoder that becomes at most one detection. In Grounding DINO each query has two parts. The position part is an anchor box: where the query starts to look. The content part is a learned vector. Query selection fills the position part from the image tokens that match the prompt best; the content part is the same for every image.
