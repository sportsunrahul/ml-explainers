Find boxes first, then borrow CLIP's names

Two-stage detection and ViLD

The first stage boxes objects it cannot name

A two-stage first turns the image into a grid of features. At every grid cell it places a few fixed boxes, called anchors. A scores each anchor for "is there an object here?" and nudges it onto the object. The best boxes survive as proposals. Then cuts each proposal out of the feature grid, and a small head names it from a fixed list.

The forklift gets a box although no training label said "forklift": the network learned what objects look like, not what they are called. Then the head calls it background. ViLD measured the real effect: a proposal network trained without the rare classes recalls them only about 2 points worse (ViLD Table 1).

Swap the fixed list for CLIP text vectors

ViLD keeps the two-stage detector and replaces the head's class rows with CLIP text vectors of the 866 base class names (yellow), plus one learned background vector (brown). Each box becomes a region embedding (blue), scored by cosine against those rows in a . Training pulls each labelled box toward its name.

A box on an unlabelled forklift matches no labelled box, so this loss calls it background and pulls it toward the brown point. Text alone reaches 10.1 rare-class AP.

Copy CLIP's view of every box

The second loss uses no labels. Before training, CLIP embeds a crop of every proposal (small faded blue points). ViLD trains each region embedding to match its crop's CLIP embedding: . CLIP's view of a forklift crop sits near the word "forklift", so the forklift boxes land there too.

At test time CLIP is gone. The detector names every box in one pass, by cosine with the text vectors of all 1,203 class names.

The stage is a toy: a drawn warehouse with made-up scores, then a sphere standing in for an embedding space with hundreds of dimensions; drag it to turn it. The table holds the paper's numbers: rare-class mask AP on LVIS, ResNet-50 (ViLD Table 3).
