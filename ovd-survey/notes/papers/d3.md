# Described Object Detection (D3)

## 1. Identity
- Title: Described Object Detection: Liberating Object Detection with Flexible Expressions
- arXiv 2307.12813, read v2. v1 2023-07-24; v2 2023-10-11 (abs.html).
- Authors: Chi Xie (Tongji University, equal contribution) ... Shuang Liang (Tongji University, corresponding). Six authors: Xie, Zhang, Wu, Zhu, Zhao, Liang (Tongji, SenseTime Research, Zhejiang University).
- Venue: NeurIPS 2023 (abs.html comment).
- Repo: github.com/shikras/d-cube. Macro note: the LaTeX writes the dataset name as `\ddd{}` = `D$^3$`.

## 2. Core problem
OVD takes short category names; REC (referring expression comprehension) takes a full description but assumes exactly one matching object exists in the image. Real queries ("dogs without leashes", "person without a safety helmet") need both: any-length description, zero to many matches, and rejection of images with no match. The paper names this Described Object Detection (DOD) and builds an evaluation set for it.

## 3. What prior methods did and why that hurt (per the paper)
- OVD methods train on category names, so they "face constraints with long and complex descriptions" (abstract).
- REC methods output one box per (image, text) pair, so they cannot reject absent targets or find several targets; they also lack good confidence scores (abstract, Sec. 5.1).
- Bi-functional models (Grounding DINO, UNINEXT) train on OVD and REC data but use separate inference strategies per task; evaluated with REC inference they also fail to reject (Sec. 1, Sec. 5).

## 4. The one key idea
An evaluation-only benchmark with complete, dataset-wide annotation: every one of 422 descriptions is checked on every one of 10,578 images, including 106 "absence" descriptions ("... without ..."), so standard mAP and false-positive rates on images with no target become measurable.

## 5. Mechanism (benchmark construction), step by step
1. Start from GRD (a referring segmentation set): 10,578 images in 106 scenario groups, about 100 images and 3 expressions per group, 316 references (Sec. 3.3).
2. Add instance-level boxes (GRD has semantic masks only) -> 18,514 boxes (Sec. 3.2-3.3).
3. Add one absence description per scenario: 106, total 422 descriptions (Sec. 3.3). Absence descriptions are "about one quarter" of references (Sec. 3.1).
4. Complete annotation across the whole dataset: CLIP pre-filters candidate references from other groups; annotators pick positives and draw boxes (Sec. 3.2). Result: 24,282 positive and 7,788,626 negative object-text pairs (Sec. 3.3).
5. Evaluate with standard COCO-style mAP (IoU 0.5 to 0.95) in a multi-label setting (one box may match several descriptions). Two protocols: intra-scenario (each image is queried only with its own scenario's descriptions; default) and inter-scenario (each image queried with all 422; much harder, like normal detection) (Sec. 3.4). Splits FULL / PRES (presence only) / ABS (absence only).
6. For images with no instance of a description, report FPPC: the share of such images on which the model outputs any box for that description, averaged over descriptions (Sec. 5.2).

## 7. Measurement setup (analysis lens)
- Baselines (Sec. 4.1, App. B): REC: OFA-base, OFA-large (pre-trained checkpoint, not REC fine-tuned; confidence = mean of the 4 coordinate-token scores). OVD: OWL-ViT base and large (detection-fine-tuned checkpoint; boxes with score < 0.1 dropped; descriptions passed as the text queries), CORA R50. Bi-functional: Grounding DINO tiny and base, UNINEXT large and huge; both run with their REC inference (keep only the single top box per image-text pair). Proposed: OFA-DOD.
- All zero-shot: D3 images do not overlap the baselines' training data (App. B).
- Claim 1: existing methods are far from solving DOD; inter-scenario mAP is near zero for all. Measured: Table 2.
- Claim 2: REC and bi-functional methods cannot reject negatives. Measured: FPPC on no-instance images (Table 3). Falsified if FPPC were near 0 for them.
- Claim 3: OVD methods degrade with description length. Measured: mAP by length bin (short 1-3, middle 4-6, long 7-9, very long > 9 words) (Table 4). Falsified if OWL-ViT were flat across bins.
- Claim 4 (text): absence descriptions are harder ("PRES consistently superior to ABS"). Measured: Table 2 PRES vs ABS columns. The table does not support the text for several rows (see Section 10).

## 9. Limitations the paper states, and failure cases
- Small by design because complete annotation is expensive; findings may depend on the chosen descriptions and image source (Sec. 6).
- Lower customization threshold may enable misuse (Sec. 6).
- Failure cases (App., Fig. 13): for "a butterfly that doesn't stop on flowers" vs its presence twin, previous methods give "similar results for both descriptions"; for "a person in santa claus clothes without bags", most methods also give similar boxes for both. Fig. 12: OWL-ViT fires several overlapping boxes on images with no target; Grounding DINO boxes the hot air balloon and the dog but ignores "with words" and "clothed".

## 10. Outline feedback
- Supports (ch 13 item 5) in a specific form: models are insensitive to negation and modifiers. The evidence is (a) the same boxes for presence and absence twins (Fig. 13), (b) Grounding DINO and UNINEXT never reject an image (FPPC 100.0) under their REC-style inference, (c) OWL-ViT falls from 20.7 to 5.3 mAP as descriptions grow from 1-3 to 9+ words.
- Does NOT support "absence descriptions score lower" as a general claim. The text says PRES is "consistently superior" to ABS (Sec. 5.2), but Table 2 shows ABS > PRES for G-DINO-tiny (21.2 vs 18.5), G-DINO-base (22.5 vs 20.1), OWL-ViT-base (8.8 vs 8.5), OFA-base (4.3 vs 3.0) and OFA-large (4.6 vs 4.1). Our reading: models score negated queries about as well as positive ones because they ignore the negation word and the absence twin often boxes the same object class. Phrase ch 13 as "negation is ignored", not "negation lowers AP".
- Supports a practical calibration point for ch 12/13: with a score threshold, Grounding DINO trades FPPC 100.0 -> 8.5 for mAP 20.7 -> 3.8 (Supp. Table 7). Rejection of absent targets is not free; no threshold gives both.
- Inter-scenario mAP (each image queried with all 422 descriptions, like a real deployment) is at most 5.7 for every method; OWL-ViT-base 3.2, G-DINO-base 2.7. This is the number to quote for "open-ended querying in the wild".
- Caveat for the page: G-DINO and UNINEXT here use REC inference (top-1 box per text), which forces FPPC = 100. OWL-ViT uses its own 0.1 threshold. Say so whenever FPPC is shown.
- Not industrial: images are GRD web scenes. Use D3 for the language-structure failure, not for domain shift.
