Every model in the SAM line answers the same request. Someone points at an image with a prompt (a click, a box, a word), and the model returns a mask: the set of pixels that belong to the thing. The models before SAM, in chapter 1, take no prompt at all, and SAM 3D, at the end of the line, returns a 3D shape instead of a mask. The papers differ in what counts as a prompt, how many answers come back, and what the model had to see to learn it. One color key holds for the whole page:
