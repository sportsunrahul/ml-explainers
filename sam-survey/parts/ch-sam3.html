SAM 3: every object of this kind

SAM and SAM 2 answer "which pixels belong to this object?" for one prompt at a time. SAM 3 (first posted 2025-11-20) answers "where is every object of this kind?" from a short phrase such as "leaf", from example boxes, or from both, and returns a mask for each instance.

Before you press "yellow mug", guess. The mug in the scene is grey. A detector that judges each region on its own sees something that looks very much like a mug. What stops it from answering "here is your yellow mug"?

The paper calls the task promptable concept segmentation (PCS). A concept is a short noun phrase, a set of exemplar boxes (each marked positive or negative), or both. The output is every matching instance, and in a video each instance keeps one identity across frames for clips of up to 30 secs.

A detector with a presence token

The detector is built like DETR. A fixed set of learned queries passes through a transformer decoder; each query ends as one proposed object with a box, a mask and a score. SAM 3 adds one more token to the decoder, the presence token. It does not look for any instance. It answers one question for the whole image: is this phrase here at all? The authors split the decision in two because "is it here" needs the whole image, while "is this region an instance" is local, and asking each query to do both "can conflict with the localization objectives that are by nature very local" (App. C.2).

\htmlData{step=1, link=total}{\htmlClass{t-green}{p(\text{query}_i \text{ matches NP})}} = \htmlData{step=2, link=query}{p(\text{query}_i \text{ matches NP}\mid \text{NP appears in image})} \cdot \htmlData{step=3, link=presence}{\htmlClass{t-blue}{p(\text{NP appears in image})}}

SAM 3 v2, App. C.2, "Presence Head" (unnumbered display).

  • \htmlClass{t-green}{p(\text{query}_i \text{ matches NP})}: the total score of query i. A mask is kept when it is above 0.5.
  • The first factor is the query's own score: how well its region matches the noun phrase (NP), if the phrase is in the image. It only has to localise.
  • \htmlClass{t-blue}{p(\text{NP appears in image})}: the presence score, one number from the presence token, shared by every query.

The training rule follows from the split. The presence head is trained with a binary cross-entropy loss on every image (weight 20). The query scores are trained only when the phrase is present. When it is absent, no query score gets a gradient, so only the presence head learns what absence looks like. Supervising the query scores only when the phrase is present gave 54.0 on the paper's main benchmark (cgF1, defined below), against 52.2 for the usual DETR rule of supervising them always. These are ablation runs (a smaller, shorter-trained model on an internal version of the benchmark); the best row, 54.9, also supervises the total score (Table 10).

What the presence token and hard negatives buy, honestly

A hard negative is a phrase that is not in the image but names something that looks similar: "yellow mug" for a grey mug. The data engine adds them on purpose. Set the figure to "yellow mug" and switch hard negatives off and on. In the toy, only the presence score moves; the query for the mug still looks like a mug either way (our reading of the mechanism). The paper's ablation measures whole models, not the presence score alone, but its numbers fit that picture. As hard negatives go from none to 30 per image, image-level accuracy (IL_MCC, defined below) rises from 0.44 to 0.68, while mask quality (pmF1) stays flat at 62.4 and 62.8 (Table 9b).

The presence head is not free. Adding it raised IL_MCC from 0.77 to 0.82, but lowered pmF1 from 65.4 to 63.4. The combined score still rose by +1.5 (Table 9a, shorter training runs). SAM 3 also does not beat SAM 2 on everything. On the interactive point benchmark (SA-37) with one click it scores 66.1 mIoU against 66.4 for SAM 2.1 L, and it runs at 43.5 frames per second against 93.0 (Table 7).

Exemplars, and ambiguity again

Words are not always enough. An exemplar is a box drawn on one instance, marked positive ("more like this") or negative ("not this"). Each exemplar becomes a prompt token from its position, its label and the image features inside the box. In the figure, one positive box on a small leaf brings in the two sideways leaves that the word alone missed, and one negative box removes the window frame from "window pane". With one exemplar and no text, SAM 3 beat the earlier exemplar model T-Rex2 by +18.3 AP+ on COCO, a metric scored on positive examples only: 76.8 against 58.5 (Table 3).

SAM 1 met ambiguity with three masks per click (chapter 3). SAM 3 meets it at the level of concepts. "Window" may mean the whole window or each pane. An ambiguity head holds 2 experts trained winner-takes-all, the same rule as SAM's three masks: only the expert with the lowest loss gets a gradient, so each learns one reading. It is trained on top of a frozen SAM 3 and cut overlapping instances by 15% (App. C.2).

Inside SAM 3: forward, then backward

SAM 3 has about 850M parameters (the README says 848M). Most of them sit in one backbone, the Perception Encoder (PE), whose image and text encoders were first trained together contrastively on 5.4 billion image-text pairs (stage 1). The detector and the video tracker share that backbone. Step through the detector's training stages 2 and 3; stage 4, the tracker, is the second figure.

Detect, then match, in video

In a video, SAM 3 runs the detector on every frame and the tracker on every known object, then reconciles the two:

\hat{\mathcal{M}}_{t} = \mathrm{propagate}(\mathcal{M}_{t-1}), \quad \mathcal{O}_{t} = \mathrm{detect}(I_{t}, P), \quad \mathcal{M}_{t} = \mathrm{match\_and\_update}(\hat{\mathcal{M}}_{t}, \mathcal{O}_{t})

SAM 3 v2, Sec. 3 (unnumbered). \mathcal{M}: the tracked objects ("masklets"); \mathcal{O}_t: the detections on frame t; P: the prompt.

A detection that overlaps no tracked object starts a new one. A few simple rules keep the identities clean (App. C.3):

  1. Wait before you trust. A new object is confirmed only after 15 more frames. If it matched detections in fewer frames than it missed them, it is removed.
  2. Remove duplicates. Two tracks that both overlap the same detection (IoU above 0.1) for half of that window are one object; the younger track goes.
  3. Re-anchor on good detections. Every 16 frames, if a detection matches a track with IoU and both scores at least 0.8, the track restarts from the detection's mask.

Claim card: the SA-Co data engine and the cgF1 metric

Claim
Language models used as "AI verifiers", plus adversarial hard negatives, let a data engine label concepts exhaustively at a scale people alone could not reach.
How
Four phases. Phase 1: a captioner and a parser propose phrases, SAM 2 prompted by an open-vocabulary detector proposes masks, and people verify them (4.3M image-phrase pairs). Phase 2: Llama models fine-tuned on those decisions take over two checks, "is this mask right?" and "are all instances found?"; SAM 3 is retrained 6 times (122.2M pairs). Phase 3: more domains (the high-quality set spans 15) and long-tail phrases mined from a Wikidata-based ontology of 22.4M nodes (17 top-level categories, 72 sub-categories). Phase 4: video.
Result
The AI verifiers match people: 77.7 against 75 on mask checks and 81.1 against 81.8 on exhaustivity (Table 23). A negative phrase took 71 seconds for a person and 6 with the full engine. The high-quality set, verified by people and AI verifiers, has 4M unique phrases on 5.2M images with 52M masks; 88.5% of its image-phrase pairs are negatives. The synthetic set adds 1.4B masks with no people involved.
Falsified if
Models trained on verifier-labelled data scored no better than on human-only data, or the verifiers disagreed with people far more than people disagree with each other.

A benchmark with 207K unique phrases (the README says 270K), most of them on images where the phrase is absent, breaks the usual detection metric, average precision. Its average over tens of thousands of rare classes is mostly noise, and it ignores whether the scores are calibrated. The paper's metric multiplies two parts:

\mathrm{cgF}_1 = 100 \cdot \mathrm{pmF}_1 \cdot \mathrm{IL\_MCC}

SAM 3 v2, App. E.3, Eq. 3.

  • \mathrm{pmF}_1: mask quality on images where the phrase is present: F1 over matched instances, averaged over IoU thresholds from 0.5 to 0.95 (Eq. 1).
  • \mathrm{IL\_MCC}: image-level correctness, a Matthews correlation between "the phrase is here" and "the model predicted something" (Eq. 2). It ignores mask quality.

On the benchmark's Gold split, SAM 3 scores 54.1 cgF1, more than double the strongest baseline (OWLv2* at 24.6), and 74% of the human score of 72.8 (Table 1). The paper gives four human numbers for this split: 72.8 in Table 1, 76.2 for the oracle protocol on a three-reviewer subset (Table 29; SAM 3's Gold score also uses the oracle protocol, so this is the like-for-like number), 55.5 on the same subset when one reviewer is scored against one other at random, and 70.8 on the internal version used for ablations. On LVIS, a standard benchmark with a long tail of rare classes, SAM 3 reaches 48.5 zero-shot mask AP in Table 1, against 38.5 for the best earlier zero-shot model (DINO-X, as reported in its own paper; models trained on LVIS score higher); the introduction states 48.8, and the paper does not explain the difference.

Object Multiplex (version 2 appendix)

The paper's video pipeline processes each object separately, so video cost grows with the number of objects. The version 2 appendix (we read only version 2; the README dates the SAM 3.1 Object Multiplex release 2026-03-27) packs objects into buckets of 16 slots that share one memory, with a per-object embedding to keep identities apart. At 128 objects it is 5.2x faster on one H100; with a single object it costs about 7% more time. Both figures use the authors' optimised internal implementation (App. H).

The limits matter for inspection. The paper says SAM 3 "struggles to generalize to fine-grained out-of-domain concepts (e.g., aircraft types, medical terms) in a zero-shot manner, especially in niche visual domains (e.g., thermal imagery)", and that it accepts only simple noun phrases (App. B). Its remedy is a few labelled examples. On RF-100VL, a benchmark of 100 datasets from varied real-world domains, zero-shot SAM 3 scores 15.2 box AP, slightly below Grounding DINO-T at 15.7. Fine-tuned on the official 10-shot splits (ten labelled examples per class, per dataset), it reaches 36.5 (Table 2). Chapter 14 returns to this.
