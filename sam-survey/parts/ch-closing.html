Summary

Segmentation models used to learn a fixed list of classes from one labelled dataset. Interactive segmentation showed another way: let a person point, feed the last mask back, and train on simulated clicks. SAM made that the whole task, "a valid mask for any prompt", returned three masks for an ambiguous click, split the cost into a heavy encoder that runs once and a light decoder that runs per click, and grew its own training set with a data engine that ended fully automatic. SAM 2 added a memory so one click follows an object through a video. SAM 3 changed the prompt from "this object" to "this kind of object" and separated "is it here?" from "where is each one?". SAM 3D turned a mask into a 3D object with the same data-engine recipe. Around this line grew faster encoders, sharper masks, domain adaptations and pipelines. For inspection, our reading of the papers is that SAM is a useful labelling tool and a source of pseudo-labels, and a weak zero-shot defect detector.
