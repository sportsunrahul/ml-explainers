Four ways to draw a mask

A mask is the set of pixels that belong to one thing, drawn as a filled shape on the image. Before 2023, most segmentation models learned to draw masks for a fixed list of classes, from one labelled dataset. Step through four of them on the same desk scene.

FCN (2014) took an image classifier and made every layer a convolution, so one forward pass gives a score for every class at every location. The scores come out on a coarse grid: one cell per 32 pixels. FCN then adds finer scores from earlier layers to sharpen the edges. On a subset of the PASCAL VOC 2011 validation set, the mean overlap (mean IU) went from 59.4 at stride 32 to 62.7 at stride 8. The output has 21 channels: the 20 PASCAL classes plus background.

U-Net (2015) made that idea symmetric. A contracting path shrinks the image and an expanding path grows it back, and skip connections copy detail from each level of the first path to the matching level of the second. It was built for cell images with very few labels: 30 training images for one challenge, and 2 output classes. In our reading, its encoder-decoder shape with skip connections is still the template for many dense-prediction networks.

Mask R-CNN (2017) asked a different question: which pixels belong to this object? It detects each object with a box, cuts the features inside the box, and predicts a small 28x28 mask for it, one per class (80 COCO classes). Two cups become two masks, not one blob. That is instance segmentation; labelling pixels by class alone is semantic segmentation.

MaskFormer (2021) and Mask2Former (2021) dropped both the per-pixel classifier and the boxes. A transformer decoder holds a fixed set of queries, 100 by default, as in DETR's object queries. Each query predicts a class (or "no object") and a mask. The mask comes from a dot product between the query's embedding and the embedding of every pixel:

  • \htmlClass{t-green}{m_i[h,w]}: how strongly pixel (h,w) belongs to mask i, between 0 and 1.
  • \htmlClass{t-green}{\mathcal{E}_{\text{mask}}[:,i]}: the embedding that query i ends with, a vector of 256 numbers.
  • \htmlClass{t-blue}{\mathcal{E}_{\text{pixel}}[:,h,w]}: the embedding of one pixel, the same length, from a pixel decoder that runs at a quarter of the image resolution.

Mask2Former's change is masked attention: each query looks only at the pixels inside the mask it predicted one layer earlier. In an ablation with a ResNet-50 backbone, removing it changes COCO instance AP by -5.9. With it, one architecture matched or beat the specialised models on all three tasks. The best results use a Swin-L backbone (with 200 queries on COCO): 57.8 PQ on COCO panoptic, 50.1 AP on COCO instances and 57.7 mIoU on ADE20K. Panoptic segmentation is the union of the two others: every pixel gets a class, and every countable object also gets its own mask.

Even the "universal" Mask2Former is trained again for each task and each dataset. Its authors name the goal they did not reach: "a model that can be trained only once for multiple tasks and even for multiple datasets" (Mask2Former v3, Sec. 4.6). A second line of work had a piece of the answer. It did not ask the model to know any classes at all. It asked a person to point.
