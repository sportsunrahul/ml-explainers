Associative recall, MQAR

A test of looking things up in the context. The model sees pairs such as "A 4 B 3 C 6", then a key such as "B", and must answer with its value, "3". Multi-query associative recall (MQAR), from the Zoology paper, puts many pairs and many queries in one sequence, which is closer to real text than one query at the end.

Phone book task

The prompt lists names with phone numbers, then asks for one person's number. The model must copy the right number exactly. A Transformer can look back at the line; a model with a fixed state must have kept it. Repeat After Me and NVIDIA's 8B study both use it.

Copying task

The model reads a string of random tokens and must then write it out again, token for token. Copying L tokens from an alphabet of D needs about L log2 D bits of memory, so a fixed state must fail once strings get long enough (Repeat After Me, Corollary 2.8).

Hybrid model

A stack that mixes layer types: mostly state-space (Mamba) layers, which keep a fixed state, and a few attention layers, which keep a KV cache. Jamba, Nemotron-H and NVIDIA's Mamba-2-Hybrid use global attention; Griffin uses local attention over a window of 1024 tokens.

Mixture of experts (MoE)

A layer with several expert MLPs and a small router. For each token the router picks a few experts (Jamba: 2 of 16) and only those run. The model can store many parameters but use only some of them for each token: Jamba stores 52B and uses 12B.

State tracking

Following a quantity that changes step by step, such as the order of objects after a series of swaps. Illusion of State shows that S4 and Mamba, like Transformers, cannot do this exactly for every length at a fixed depth, assuming a widely believed complexity conjecture (TC0 is not NC1) and log-precision arithmetic. It is a different limit from recall.
