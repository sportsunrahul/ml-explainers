Linear attention

Attention with the softmax removed. Softmax attention weighs past token s for query t by exp(qt · ks), normalized over the row. Linear attention (Katharopoulos et al., 2020) uses φ(qt) · φ(ks) instead, for a fixed feature map φ. Then the sum over the past can be kept as a running matrix S = Σ φ(ks) vsᵀ, so each new token costs the same and no KV cache is needed: the layer becomes a recurrent network.

Feature map

A fixed function φ applied to each query and key vector before their dot product. Linear attention uses φ(x) = elu(x) + 1, which is always positive, so every similarity is positive, as with exp. Mamba-2 applies SiLU to its B and C. Softmax's exp would need a feature map with infinitely many features, which is why SSD cannot express softmax attention.

Associativity

A product of three matrices can be grouped either way: (A B) C = A (B C). In attention, (φ(Q) φ(K)ᵀ) V first builds a T × T score matrix, which costs work growing with T². φ(Q) (φ(K)ᵀ V) first builds a small matrix the size of the features by the values, so the work grows only with T. Same answer, different cost.

Semiseparable matrix

A lower-triangular matrix is N-semiseparable if every block on or below its diagonal has rank at most N (Mamba-2 Definition 3.1). Every SSM with state size N is multiplication by such a matrix. Low rank means each block factors through N numbers, and those N numbers are the state. Mamba-2 also proves the converse: masked attention with a fast recurrent form must have a semiseparable mask.

Chunk

A run of Q consecutive tokens. The SSD algorithm splits the sequence into chunks. Inside each chunk it computes outputs like attention, all chunks at once. Across chunks it passes only the state: each chunk's final state, a short recurrence over chunks, and each chunk's outputs from the state that entered it. Q = 1 is the plain recurrence; one chunk of the whole sequence is plain attention. The reference code uses chunks of 64.

Tensor core

A unit on modern GPUs that does only one thing, small matrix multiplications, and does it much faster than the general-purpose cores. Attention runs almost entirely on them. Mamba's scan is a chain of small elementwise updates and cannot use them; Mamba-2's chunked algorithm turns almost all of its work into matrix products so that it can.
