Recurrent neural network (RNN)

A network that reads a sequence one element at a time and carries a hidden state forward: h_t = f(h_(t-1), x_t). The same weights are used at every step. Classic RNNs use a squashing function such as tanh inside f; gated versions such as the LSTM (1997) and the GRU (2014) add learned gates that decide how much of the state to keep.

Generation is cheap, because each new token only updates the state. Training is slow, because step t needs step t-1 first.

Eigenvalue

A number λ for which a matrix A acts on some direction v as plain scaling: A v = λ v. Applying A k times scales that direction by λk. Most square matrices can be written A = P Λ P-1, with the eigenvalues on the diagonal of Λ; in that basis a recurrence h_t = A h_(t-1) + B x_t splits into independent cells, one per eigenvalue.

For a matrix that is not symmetric, the eigenvalues are in general complex numbers. LRU learns them directly.

Complex number

A number with two parts, written r eiθ: a size r and an angle θ. Multiplying by it scales by r and rotates by θ. Multiplying k times scales by rk and rotates by kθ, so a cell with a complex λ can hold a slowly fading oscillation. A model reads out the real part. LRU notes that the same thing can be done with pairs of real numbers, as the tanh toy on this stage does.

Impulse response

What a system does after a single input of size 1 followed by nothing. For the cell h_t = λ h_(t-1) + b x_t it is b λk after k steps. For a linear system it tells you everything: the response to any input is a sum of shifted, scaled copies of it. Read backward, it is the weight each past token has in the state now.

Vanishing and exploding gradients

Training sends an error signal (the gradient) backward through every step of the recurrence. Each step multiplies it by roughly the same factor, so over many steps it shrinks toward zero or grows without bound, and the model cannot learn links between distant tokens. The problem was studied by Hochreiter (1991), Bengio, Simard and Frasconi (1994), and Pascanu, Mikolov and Bengio (2013).

Parallel scan

A way to compute all the running results of a sequence, h_1, h_2, ..., h_L, in about log L rounds instead of L, by combining neighbors in a tree. It works for any associative combine step. A linear recurrence has one: two steps "multiply by a1, add b1" then "multiply by a2, add b2" make one step "multiply by a1 a2, add a2 b1 + b2". A tanh recurrence has none, so it cannot be scanned. Martin and Cundy (ICLR 2018) applied it to linear RNNs.

Long Range Arena (LRA)

A benchmark of six classification tasks on long sequences, from 1K to 16K elements: ListOps (nested math expressions), Text (byte-level movie reviews), Retrieval (do two documents match), Image (sequential CIFAR, one pixel at a time), Pathfinder and PathX (are two dots joined by a path, on 32 x 32 and 128 x 128 images). PathX was long out of reach for every model; S4 was the first to beat chance on it.
