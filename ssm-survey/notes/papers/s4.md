# S4 -- Efficiently Modeling Long Sequences with Structured State Spaces

Notation: S4 writes the input as u, the state as x (size N), the output as y. The page writes the input
as x and the state as h. All TeX below is verbatim (S4 notation); glosses use page notation
(u -> page x, x -> page h). Custom macros: `\dt` = `\Delta`, `\methodabbrv` = `S4`, `\bm{}` = bold.
Equation numbers are the printed PDF numbers; TeX labels in parentheses.

## 2. Core problem
Sequence models fail on long-range dependencies (LRDs) of 10K+ steps; on LRA Path-X no model beat
random guessing (Sec 1). The LSSL showed that a deep SSM with the HiPPO matrix A handles LRDs, but
computing it costs O(N^2 L) operations and O(NL) memory, so it is impractical (Sec 1, Sec 3.1).

## 3. What prior methods did and why that hurt (per the paper)
- RNN/CNN/Transformer LRD variants (orthogonal/Lipschitz RNNs, dilated convs, efficient Transformers)
  "still perform poorly" on LRA and raw audio (Sec 1).
- LSSL: computes the kernel by L successive multiplications by A-bar: O(N^2 L) ops, O(NL) space,
  versus an Omega(L+N) lower bound (Sec 1, Sec 3.1). With N=256 it uses orders of magnitude more
  memory than comparable RNNs/CNNs (Sec 1).
- Diagonalizing HiPPO directly is numerically infeasible: the eigenvector matrix has entries up to
  2^{4N/3} (Lemma 3.2). The LSSL's proposed fast algorithm (O(N log^2 N + L log L)) is also
  unstable: it needs coefficients exponentially large in N (App B.2, Lemma B.1).

## 4. The one key idea
Write HiPPO's A as normal plus low-rank (NPLR), conjugate to diagonal plus low-rank (DPLR)
Lambda - P Q^*, and compute the kernel K-bar in frequency space: evaluate its truncated generating
function at the L roots of unity, where powers of A-bar become one matrix inverse; Woodbury removes the
low-rank term and the diagonal part is a Cauchy kernel. Then inverse FFT gives K-bar (Sec 3.2, Alg 1).

## 5. Mechanism, step by step
1. Init: set A to the HiPPO matrix (Eq 2). By Lemma 3.1 (conjugation) and Theorem 1 (NPLR), the SSM
   is unitarily equivalent to (Lambda - P Q^*, B, C) with diagonal Lambda and P, Q, B, C in C^{N x 1}:
   "S4's 5N trainable parameters" (Sec 3.4). Delta is also trained (in the LR-capped list, App D.2).
2. Discretize with the bilinear method and step Delta (Eq 3). S4 does not use ZOH.
3. Convolution view: unroll the recurrence to y = K-bar * u (Eq 4), K-bar = (C-bar A-bar^i B-bar)
   for i in [L] (Eq 5). Given K-bar, the convolution is one FFT convolution.
4. Naive kernel: L mat-vecs by A-bar: O(N^2 L) ops, O(NL) space (Sec 3.1).
5. S4 kernel (Algorithm 1, p.6; Theorem 3):
   a. C~ = (I - A-bar^L)^* C-bar: truncates the SSM generating function to length L. In practice
      S4 learns C~ directly instead of C (App C.3, after Lemma C.4).
   b. For each root of unity omega: the 2x2 block [C~ Q]^* (2/Delta (1-omega)/(1+omega) - Lambda)^{-1} [B P]
      -- "Black-box Cauchy kernel"; 4 Cauchy matrix-vector products over N poles and L nodes.
   c. Woodbury: K^(omega) = 2/(1+omega) [k00 - k01 (1 + k11)^{-1} k10].
   d. Evaluate at all L roots of unity, then K-bar = iFFT(K^).
   Cost: O~(N+L) ops, O(N+L) space (Theorem 3). Implementation note: the released code uses the
   naive O(NL) Cauchy algorithm (pykeops), because the fast FMM-based algorithms are not implemented
   on GPU (App A, Implementation). So: theory O~(N+L) time; implementation O(NL) time, O(N+L) memory.
6. Layer: H independent copies of the 1-D SSM (one per feature), then a position-wise linear layer
   mixes the H features; nonlinear activations between layers; O(H^2) + O(HN) params per layer
   (Sec 3.4). D u is a skip term, omitted in exposition (Sec 2.1).
7. Generation: switch to the recurrence; A-bar = A1 A0 with both DPLR, so one step is O(N)
   (Theorem 2, App C.2). Constant memory and compute per step (Sec 4.3).

## 6. Equations

**Eq (1)** (`eq:1`), continuous SSM, Sec 2.1:
```
\begin{aligned}
  x'(t) &= \bm{A}x(t) + \bm{B}u(t) \\
  y(t) &= \bm{C}x(t) + \bm{D}u(t)
\end{aligned}
```
Paper: maps "a 1-D input signal u(t) to an N-D latent state x(t) before projecting to a 1-D output
signal y(t)". Gloss: u(t) = page input x(t) (one channel); x(t) = page state h(t) in R^N; A (N x N)
state matrix; B (N x 1) input map; C (1 x N) readout; D scalar skip. "we will omit the parameter D
... because the term Du can be viewed as a skip connection and is easy to compute."

**Eq (2)** (`eq:hippo`), HiPPO matrix, Sec 2.2:
```
(\text{\textbf{HiPPO Matrix}})
\qquad
\bm{A}_{nk}
=
-
\begin{cases}
  (2n+1)^{1/2}(2k+1)^{1/2} & \mbox{if } n > k \\
  n+1 & \mbox{if } n = k \\
  0 & \mbox{if } n < k
\end{cases}
.
```
Gloss: lower-triangular, real, negative diagonal -(n+1) (stable). Row n = Legendre coefficient n.
This is HiPPO-LegS (S4D calls it that; App D.5 calls the S4 model "S4-LegS"). Source typo: App C.1
proof says "equation (2) is the HiPPO-LegT matrix"; the LegS paragraph of the same proof restates
Eq (2), so read LegS. S4 v3 gives no formula for B; S4D Eq (4) gives B_n = (2n+1)^{1/2}.
Sec 2.2: replacing a random A with Eq (2) took the LSSL's sMNIST from 60% to 98%.

**Eq (3)** (`eq:2`), bilinear discretization, Sec 2.3:
```
\begin{aligned}
  x_{k} &= \bm{\overline{A}} x_{k-1} + \bm{\overline{B}} u_k &
  \bm{\overline{A}} &= (\bm{I} - \dt/2 \cdot \bm{A})^{-1}(\bm{I} + \dt/2 \cdot \bm{A}) &
  \\
  y_k &= \bm{\overline{C}} x_k &
  \bm{\overline{B}} &= (\bm{I} - \dt/2 \cdot \bm{A})^{-1} \dt \bm{B} &
  \bm{\overline{C}} &= \bm{C}
  .
\end{aligned}
```
Paper: "a sequence-to-sequence map u_k -> y_k"; "x_k can be viewed as a hidden state with transition
matrix A-bar". Gloss: u_k = page x_k = u(k Delta); x_k = page h_k; Delta = step size ("the resolution
of the input"). Note for ch 2: Mamba uses ZOH (Mamba Eq 4); S4 uses bilinear; S4D Sec 3.1 shows both
and finds little empirical difference.

**Eq (4)** (`eq:convolution`), Sec 2.4:
```
\begin{split}
  y_k &= \bm{\overline{C}} \bm{\overline{A}}^k \bm{\overline{B}} u_0 + \bm{\overline{C}} \bm{\overline{A}}^{k-1} \bm{\overline{B}} u_1 + \dots + \bm{\overline{C}} \bm{\overline{A}} \bm{\overline{B}} u_{k-1} + \bm{\overline{C}}\bm{\overline{B}} u_k
  \\
  y &= \bm{\overline{K}} \ast u %
  .
\end{split}
```
Assumes x_{-1} = 0. Paper: "a single (non-circular) convolution and can be computed very efficiently
with FFTs, provided that K-bar is known."

**Eq (5)** (`eq:krylov`), the SSM convolution kernel, Sec 2.4 (reuse in ch 2 and ch 4):
```
\bm{\overline{K}} \in \mathbb{R}^L :=
\mathcal{K}_L(\bm{\overline{A}}, \bm{\overline{B}}, \bm{\overline{C}}) := \left(\bm{\overline{C}} \bm{\overline{A}}^i \bm{\overline{B}}\right)_{i \in [L]} = (\bm{\overline{C}}\bm{\overline{B}}, \bm{\overline{C}}\bm{\overline{A}}\bm{\overline{B}}, \dots, \bm{\overline{C}}\bm{\overline{A}}^{L-1}\bm{\overline{B}})
.
```
Paper: "We call K-bar the SSM convolution kernel or filter." Gloss: entry i = how much the input i
steps ago contributes to the current output; L = sequence length.

**Lemma 3.1** (`lmm:conjugation`): `(\bm{A}, \bm{B}, \bm{C}) \sim (\bm{V}^{-1} \bm{A} \bm{V}, \bm{V}^{-1}\bm{B}, \bm{C}\bm{V})`.
Same operator u -> y; the state is a change of basis (x = V x~).

**Lemma 3.2** (`lmm:hippo-diagonalization`): HiPPO is diagonalized by `\bm{V}_{ij} = \binom{i+j}{i-j}`;
`\bm{V}_{3i,i} = \binom{4i}{2i} \approx 2^{4i}`; "V has entries of magnitude up to 2^{4N/3}".

**Eq (6)** (`eq:nplr`), **Theorem 1** (`thm:hippo-nplr`), p.6:
```
\bm{A} = \bm{V} \bm{\Lambda} \bm{V}^* - \bm{P} \bm{Q}^\top = \bm{V} \left( \bm{\Lambda} - \left(\bm{V}^* \bm{P}\right) (\bm{V}^*\bm{Q})^* \right) \bm{V}^*
```
"for unitary V in C^{N x N}, diagonal Lambda, and low-rank factorization P, Q in R^{N x r}. These
matrices HiPPO- LegS, LegT, LagT all satisfy r=1 or r=2. In particular, equation (2) is NPLR with r=1."
Note the first form has `Q^\top` (real P, Q), the second `(V^* Q)^*`; after conjugation the paper
writes the DPLR form as `\bm{\Lambda} - \bm{P}\bm{Q}^*` over C (Sec 3.3, Alg 1). For LegS the proof
(App C.1) adds `\frac{1}{2}(2n+1)^{1/2}(2k+1)^{1/2}` to get `\frac{1}{2}\bm{I} + \bm{S}` with S
skew-symmetric, i.e. P = Q with P_n = (n+1/2)^{1/2} (our reading; matches S4D Eq (4)). Sec 3.4:
follow-up work (SaShiMi) changed `\bm{\Lambda} - \bm{P}\bm{Q}^*` to `\bm{\Lambda} - \bm{P}\bm{P}^*`
to avoid eigenvalues in the right half-plane.

**Theorem 2** (S4 Recurrence): "computing one step of the recurrence (3) can be done in O(N) operations".
**Theorem 3** (S4 Convolution): "computing the SSM convolution filter K-bar can be reduced to 4 Cauchy
multiplies, requiring only \widetilde{O}(N+L) operations and O(N+L) space."

**Algorithm 1** (`alg:s4-convolution`), p.6, verbatim lines:
```
\Require{\methodabbrv{} parameters \( \bm{\Lambda}, \bm{P}, \bm{Q}, \bm{B}, \bm{C} \in \mathbbm{C}^N \) and step size \( \dt \)}
\Ensure{SSM convolution kernel \( \bm{\overline{K}} = \mathcal{K}_L(\bm{\overline{A}}, \bm{\overline{B}}, \bm{\overline{C}}) \) for \( \bm{A} = \bm{\Lambda} - \bm{P}\bm{Q}^* \)}
\State $\bm{\widetilde{C}} \gets \left(\bm{I} - \bm{\overline{A}}^L\right)^* \bm{\overline{C}}$   % Truncate SSM generating function (SSMGF) to length L
\State \( \begin{bmatrix} k_{00}(\omega) & k_{01}(\omega) \\ k_{10}(\omega) & k_{11}(\omega) \end{bmatrix} \gets \left[ \bm{\widetilde{C}} \; \bm{Q} \right]^* \left(\frac{2}{\Delta} \frac{1-\omega}{1+\omega} - \bm{\Lambda} \right)^{-1} \left[ \bm{B} \; \bm{P} \right] \)   % Black-box Cauchy kernel
\State \( \bm{\hat{K}}(\omega) \gets \frac{2}{1+\omega} \left[ k_{00}(\omega) - k_{01}(\omega) (1 + k_{11}(\omega))^{-1} k_{10}(\omega) \right]  \)   % Woodbury Identity
\State \( \bm{\hat{K}} = \{\bm{\hat{K}}(\omega) : \omega = \exp(2\pi i \frac{k}{L})\} \)   % Evaluate SSMGF at all roots of unity
\State \( \bm{\overline{K}} \gets \mathsf{iFFT} (\bm{\hat{K}}) \)   % Inverse Fourier Transform
```
Sign note: Alg 1 uses exp(+2 pi i k/L); Lemma C.2 uses exp(-2 pi i k/L). Do not reconcile on the page.

**Eq (10)** (`eq:generating-function`), SSM generating function, Def 2, App C.3 (C transposed to a column, Remark C.1 / Eq (8)):
```
\hat{\mathcal{K}}(z; \bm{\overline{A}}, \bm{\overline{B}}, \bm{\overline{C}}) \in \mathbbm{C} := \sum_{i=0}^\infty \bm{\overline{C}}^* \bm{\overline{A}}^i \bm{\overline{B}} z^i
= \bm{\overline{C}}^* (\bm{I} - \bm{\overline{A}} z)^{-1} \bm{\overline{B}}
```
Eq (11), truncated: `\sum_{i=0}^{L-1} ... = \bm{\overline{C}}^* (\bm{I} - \bm{\overline{A}}^L z^L) (\bm{I} - \bm{\overline{A}} z)^{-1} \bm{\overline{B}}`.
Paper: "turns powers of A-bar into a single inverse". At roots of unity z^L = 1, and the values are
the DFT of K-bar (Lemma C.2), recovered by one inverse FFT in O(L log L).

**Proposition 4** (Woodbury), App C.3:
`(\bm{A} + \bm{U}\bm{V}^*)^{-1} = \bm{A}^{-1} - \bm{A}^{-1}\bm{U}(\bm{I}_p + \bm{V}^*\bm{A}^{-1}\bm{U})^{-1}\bm{V}^*\bm{A}^{-1}`

**Lemma C.3** (`lmm:resolvent-woodbury`):
```
\bm{\hat{K}}(z) &=
\frac{2}{1+z}\left[ \bm{\tilde{C}}^* \bm{R}(z) \bm{B} - \bm{\tilde{C}}^* \bm{R}(z) \bm{P} \left( 1 + \bm{Q}^* \bm{R}(z) \bm{P} \right)^{-1} \bm{Q}^* \bm{R}(z) \bm{B} \right]
\\
\bm{\tilde{C}} &= (\bm{I}-\bm{\overline{A}}^L)^* \bm{C}
\\
\bm{R}(z; \bm{\Lambda}) &= \left(\frac{2}{\dt} \frac{1-z}{1+z} - \bm{\Lambda}\right)^{-1}
```
Gloss: R(z) is diagonal, so each term is a sum over the N eigenvalues: sum_j q_j^* p_j / (omega - lambda_j).

**Definition 3** (Cauchy matrix): `\bm{M}_{ij} = \frac{1}{\omega_i - \lambda_j}`.
**Proposition 5** (Cauchy), costs of an M x N Cauchy mat-vec: O(MN) naively;
O((M+N) log^2(M+N)) in exact arithmetic; O((M+N) log(M+N) log(1/eps)) numerically; O(M+N) space.

## 7. Config / setup (architecture lens)

S4 layer, forward, shapes (Sec 3.4 + our reading for the shape bookkeeping):
- Input (B, L, H). Each of the H channels has its own SSM: Lambda, P, Q, B, C~ in C^N, and Delta.
- Kernel generation: per channel, Alg 1 -> K-bar in R^L; all channels -> (H, L).
- FFT convolution per channel -> (B, L, H); plus D u skip (D per channel: our reading).
- Nonlinearity: the paper says only "Nonlinear activation functions are also inserted between these
  layers" (Sec 3.4). GELU is NOT named in S4 v3 or in `sources/s4/README.md`. WT103 used "a GLU
  activation after the S4 linear layer" (App D.3.2). S4D App B describes S4's output mixing as
  W y, W in R^{H x H}, and the updated LRA runs replace it with GLU (W1 y) o sigma(W2 y).
- Output mixing: position-wise linear layer over H (Sec 3.4).
- Norm: BN or LN, pre-norm or post-norm, per task (Table 11). Residual connections: not stated in
  S4 v3 for the classification backbone (our reading: implied by the "Pre-norm" column).
- Classification head: mean pooling over L after the last layer (App D.2); decoder not described.
- Recurrent mode: per channel state in C^N (DPLR form), so (B, H, N); O(N) per step (Theorem 2).
- Causality: v3's S4 layer is causal; the updated LRA numbers use a bidirectional S4 (two kernels
  back-to-back) per S4D App B.

Trainable and gradients:
- Per SSM copy: 5N complex parameters Lambda, P, Q, B, C (Sec 3.4), plus Delta. C~ learned directly
  instead of C (App C.3). All get gradients from the task loss through iFFT, Woodbury and the Cauchy
  sums (our reading). LR on (Lambda, P, Q, B, C, Delta) capped at a max starting LR of 0.001
  "since the HiPPO equation is crucial to performance" (App D.2). README (code-only): lower LR and
  weight decay always 0 on (A, B), sometimes Delta.
- Delta init / log-step range: NOT in S4 v3. S4D Listing 1: log_dt uniform between log(1e-3) and
  log(1e-1) ("Geometrically uniform timescale"); S4D Table 12: (0.001, 0.1), Path-X (0.0001, 0.01);
  S4D Sec 3.4: Delta init "the same as in S4 and DSS". Attribute to S4D.
- B init: S4D Eq (4) B_n = (2n+1)^{1/2}. C init: random, std 1 (S4D Sec 3.3, citing HTTYH). Neither
  stated in S4 v3.
- Conjugate symmetry (N/2 complex = N real) is "a minor parameterization detail originally used in
  S4" per S4D Sec 3.3; S4 v3 does not state it.

Optimizer (App D.2): AdamW, constant LR with decay on validation plateau. N = 64 for all LRA tasks
("The S4 state size was always fixed to N=64"). Single GPU; Path-X on A100 (40GB).

## 9. Limitations stated
- Gap to Transformers on language modeling remains (WT103, App A).
- Fast Cauchy algorithms are not implemented on GPU; the code uses the naive O(NL) kernel (App A).
- v3 S4 "can sometimes suffer from numerical instabilities when the A matrix has eigenvalues on the
  right half-plane"; fixed by Lambda - P P^* (SaShiMi) (Sec 3.4).
- Later fixes from given sources: S4D (2206.11893) drops the low-rank term (diagonal A) with a
  2-line Vandermonde kernel; Mamba makes B, C, Delta input-dependent (the LTI limit, ch 5-6).
