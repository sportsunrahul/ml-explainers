## 2. Core problem
SSMs trail attention on language. The paper uses synthetic tasks to find which abilities are missing, and also
shows SSMs ran slower than Transformers on GPUs (abstract).

## 3. What prior methods did and why that hurt
2-layer S4D and Gated State Spaces fail Induction Head and Associative Recall (Table 2). The paper names two
missing abilities: "(i) to remember tokens that appear after a particular event ... and (ii) to compare tokens
across the sequence" (Sec 3.1). Attention has both through Q K^T and softmax(Q K^T) V.

## 4. The one key idea
Stack two SSMs with multiplicative interactions, in the shape of linear attention: a shift SSM on K detects
"the previous token was the key", a diagonal SSM stores the value for the rest of the sequence, and Q gates
the read-out.

## 5. Mechanism (Sec 3.2, Alg. 1)
1. Q = u W_Q, K = u W_K, V = u W_V.
2. K_bar = SSM_shift(K) (A is a shift matrix: the state holds the last m inputs, a short conv).
3. Per head: outer product K_bar V^T, passed through SSM_diag (A diagonal, S4D/HiPPO init).
4. Multiply by Q; concatenate heads; output projection W_O.
5. Model: H3 layers interleaved with MLPs, pre-norm residual. Hybrid: two attention layers (layer 2 and layer
   2 + N/2).
Associative-recall mechanism (Sec 3.3, Fig. 1 middle): shift SSM x V acts as a gate that lets the value in when
the previous token was the key; SSM_diag stores it; the Q product lets it out when the current token is the key.

## 6. Equations
Unnumbered, Sec 3.2 (macros: `\vQ`=`\mathbf{Q}`, `\vK`=`\mathbf{K}`, `\vV`=`\mathbf{V}`, `\vA`=`\mathbf{A}`):
```tex
\vQ \odot \mathrm{SSM}_\mathrm{diag}(\mathrm{SSM}_\mathrm{shift}(\vK) \odot \vV),
```
Paper: output "for the case of head dimension d_h = 1"; "stacking two SSMs with multiplicative interaction (each
is a 'hungry hippo')". Gloss: odot is elementwise product; Q, K, V are linear projections of the input.
Shift matrix (Sec 3.2):
```tex
\vA_{i, j} = 
    \begin{cases}
    1 & \text{for } i - 1 = j\\
    0 & \text{otherwise}
    \end{cases}
```
Gloss: moves each state entry down one slot ([a, b, c] -> [0, a, b]); with B = e_1 the state is the last m inputs.
Proposition 1: H3 takes O(d^2 N + d N log N) time and O(dN) space (N = sequence length here).

## 7. Setup
- Synthetic tasks (Table 1): Induction Head, length 30, vocab 20; Associative Recall, length 20, vocab 10.
  2-layer GPT-style models (Table 2).
- OpenWebText ablation (Table 3): 12 layers, ~125M, 50B tokens, same hyperparameters.

## 8. Results worth remembering
- Table 2 (2-layer, accuracy): Induction Head: random 5.0, S4D 35.6, GSS 6.8, H3 100.0, attention 100.0.
  Associative Recall: random 25.0, S4D 86.0, GSS 78.0, H3 99.8, attention 100.0.  <- key number for the page.
- Table 3 (OpenWebText ppl): H3 21.0, H3 hybrid (2 attn) 19.6, S4D 24.9, GSS 24.0, GSS hybrid 19.8, Transformer 20.6.
- Generation: hybrid H3-1.3B "up to 2.4x faster" than Transformer-1.3B (Table 7: 1240 vs 520 tokens/s at prompt
  1536, batch 64).

## 9. Limitations stated / fixed later
H3's SSMs are LTI; H3 needs the shift SSM plus gating to fake content-awareness. Mamba (2312.00752) Table 1:
H3 gets 57.0 on Selective Copying vs 99.7 with S6 inside the same H3 architecture. Mamba's block is H3 merged
with a gated MLP (Mamba Fig. 3).
