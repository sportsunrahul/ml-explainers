# Fact-check (early): hippo.json, s4.json, lru.json

Date: 2026-10-10. Scope: notes/claims/hippo.json (HiPPO 125, LSSL 50), notes/claims/s4.json (S4 265, S4D 68),
notes/claims/lru.json (LRU 196, Griffin 154). Total 858 claims.

Method: a script grepped every claim value in the paper's tex (LRU: top-level main/content_main/appendix only;
the nested 'Resurrecting RNNs  Arxiv' copy is identical). Then each claim was opened at its loc and compared by
hand: table cell (row, column, model size, variant), prose wording, version, and label. Equation, theorem, table and
page numbers were checked in the compiled PDF (pdftotext -layout). Dates and versions were checked in abs.html.
Every stated ratio, speedup and margin was recomputed from the table cells. All 858 claims were checked, not a sample.

Priority 1: the first page grep found no ids from these files. The last grep (end of run) found 82 ids from
these files on ch-recurrence.html, ch-continuous.html and ch-hippo.html. All 82 claims are correct, and the ch-hippo.html
sentences that use them match the sources (one nit: the page says HiPPO-Rand uses "a random" A; it uses random A and B,
hippo/src/src/experiment_details.tex:56). One page sentence that uses
them is not supported by the sources (see "Page-usage issues").
