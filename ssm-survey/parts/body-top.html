Toy model

State-space models, intuition first

Attention keeps every token it has seen and reads all of them again for each new one. A state-space model keeps a small memory of fixed size and updates it. This is the story of how that memory was made trainable, fast and selective, and where it still falls short.

Every figure on this page draws the same three things: tokens arriving in order, a memory the model carries forward, and the output it produces. Attention's memory is its KV cache, drawn in brown, and it grows with every token; a state-space model's memory is drawn as a small yellow grid that never changes size.
