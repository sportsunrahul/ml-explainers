Mamba-2: linear attention and state-space duality

Attention and Mamba look like opposites: one keeps every token and compares them all, the other folds the past into a small state. Below is the one object both compute, a T \times T matrix M with \htmlClass{t-green}{y} = M \htmlClass{t-blue}{x}, drawn for three layers on the same random inputs; press the three buttons from left to right.

Every layer in this chapter has the same form. Stack the inputs into \htmlClass{t-blue}{x}; the outputs are \htmlClass{t-green}{y} = M\htmlClass{t-blue}{x} for a lower-triangular matrix M. Row t says how much each earlier input contributes to output t, and the triangle is causality: nothing reads the future. The layers differ only in how they build M. That decides how much work it takes to apply M, and what the model must keep in memory to produce the next row.

Softmax attention builds each entry from its own query-key pair, M_{ts} = \exp(q_t \cdot k_s) divided by the row's sum. There is no shorter description. To produce row t the model needs every key and value before it, which is the KV cache along the front edge of the figure: one key and one value per token, growing with T.

Linear attention, built from zero

In 2020, Katharopoulos and colleagues asked what happens if the exponential goes. They replace the similarity \exp(q \cdot k) with a dot product of features, \phi(q) \cdot \phi(k), where \phi is a fixed function applied to each vector (their Eq. 4). They pick \phi(x) = \mathrm{elu}(x) + 1 (Eq. 7): the exponential linear unit is x for positive x and e^x - 1 below zero, so \phi is always positive, like \exp. Now the score matrix is a product of two thin matrices, and a product of three matrices can be grouped either way:

\htmlData{step=1, link=scores}{\big(\phi(Q)\,\phi(K)^{\top}\big)\,\htmlClass{t-blue}{V}} \;=\; \htmlData{step=2, link=state}{\phi(Q)\,\big(\phi(K)^{\top}\htmlClass{t-blue}{V}\big)}

Eq. 6 in linear attention (Katharopoulos et al. 2020); rows of Q, K, V are tokens.

  • Left: first the T \times T matrix of scores (the columns in the figure), then the product with the values. The work grows with T^2.
  • Right: first \phi(K)^{\top}\htmlClass{t-blue}{V}, a small matrix (feature size by value size) that sums over all tokens, then one product per query. The work grows with T.

With a causal mask, query i may use only keys up to i, so the small matrix becomes a running sum. Call it the state. Each token adds one outer product to it, and the output reads it with the query:

\htmlData{step=1, link=state inputs}{\htmlClass{t-yellow}{s_i} = \htmlClass{t-yellow}{s_{i-1}} + \phi(k_i)\,\htmlClass{t-blue}{v_i}^{\top}} \qquad \htmlData{step=2, link=norm}{\htmlClass{t-yellow}{z_i} = \htmlClass{t-yellow}{z_{i-1}} + \phi(k_i)} \qquad \htmlData{step=3, link=output}{\htmlClass{t-green}{y_i} = \frac{\phi(q_i)^{\top}\htmlClass{t-yellow}{s_i}}{\phi(q_i)^{\top}\htmlClass{t-yellow}{z_i}}}

Eqs. 18, 19 and 20 in linear attention, with s_0 = 0 and z_0 = 0; in Eq. 20 the layer also adds the residual and its feedforward network. The sums they unroll are Eqs. 10 to 12.

  • \htmlClass{t-yellow}{s_i}, the "attention memory": a matrix of feature size by value size, the same size at every step. Writing a token means adding the outer product of its key features and its value \htmlClass{t-blue}{v_i}.
  • \htmlClass{t-yellow}{z_i}, the "normalizer memory": a running sum of key features. Dividing by \phi(q_i)^{\top}\htmlClass{t-yellow}{z_i} does the job of softmax's row sum.
  • \htmlClass{t-green}{y_i}: the memory read with the query's features. Constant work and constant memory per generated token, which is the paper's title: Transformers are RNNs.

Press Linear attention. The matrix keeps its full triangle, so where did the KV cache go? Look at the front edge before you read on. The brown cubes are gone; a yellow 2 \times 2 state and its normalizer replace them. The yellow line along the front edge shows how much of each token is still in the state at the last step, and it is flat at 1. Linear attention never forgets: every token stays in the sum with full weight.

How much faster, against which baseline

The linear attention paper generates images 317x (MNIST) and 4,462x (CIFAR-10) faster than softmax attention. Both baselines recompute attention over the whole prefix for every new pixel: they keep no KV cache. Against a softmax baseline that does cache keys and values (its appendix calls it "stateful softmax"), linear attention is still more than 50x faster on CIFAR-10. That is the fair number for a reader who knows the KV cache. Quality was close on images (3.47 bits per dimension for softmax, 3.40 for linear) and worse on speech (phone error rate 5.12 for softmax, 8.08 for linear).

Mamba-2: the same matrix, with a decay

Now come from the other side. Take Mamba's selective SSM and restrict its state matrix to one number times the identity, A_t = a_t I, with a_t between 0 and 1 and set by the input. For a head with P channels the state is an N \times P matrix, and the update is

\htmlClass{t-yellow}{h_t} = a_t\, \htmlClass{t-yellow}{h_{t-1}} + B_t\, \htmlClass{t-blue}{x_t}^{\top}, \qquad \htmlClass{t-green}{y_t} = C_t^{\top}\, \htmlClass{t-yellow}{h_t}

Mamba-2 Eq. 2 with A_t = a_t I, written for P channels at once.

Set a_t = 1 and this is the linear attention recurrence above, with C as the query features, B as the key features and \htmlClass{t-blue}{x} as the value, minus the normalizer. Linear attention is an SSM that never forgets. Unroll the recurrence and each output is a weighted sum of the inputs, \htmlClass{t-green}{y_t} = \sum_{s \le t} C_t^{\top} (a_t \cdots a_{s+1}) B_s \htmlClass{t-blue}{x_s} (Eq. 3): a score C_t^{\top} B_s times a decay a_t \cdots a_{s+1}. As one matrix:

\htmlData{step=1, link=output}{\htmlClass{t-green}{y}} = \big(\htmlData{step=2, link=decay}{\htmlClass{t-yellow}{L}} \circ \htmlData{step=3, link=scores}{\htmlClass{t-brown}{C B^{\top}}}\big)\, \htmlData{step=4, link=inputs}{\htmlClass{t-blue}{x}}, \qquad \htmlData{step=2, link=decay}{\htmlClass{t-yellow}{L_{ts}} = a_t \cdots a_{s+1} \ \ (t \ge s)}

Press SSD: decay mask. The scores are linear attention's, but each column now shrinks with its distance from the diagonal, and the token with a = 0.12 cuts a step into the surface: almost nothing before it survives. That is Mamba's selection, written as a mask on attention. The paper calls the equivalence state-space duality (SSD): read one way the layer is an SSM, read the other way it is masked attention (Corollary 5.1). The link also runs in reverse. Theorem 5.2 proves that any masked kernel attention that runs as a recurrence with a bounded state must use a semiseparable mask, so every such linear attention is an SSM.

The price is expressiveness. Mamba gives every channel its own decay; Mamba-2 shares one decay per head, which the paper calls "slightly decreasing the expressive power in return for significant training efficiency improvements" (Sec 2.4). And SSD cannot express softmax attention, whose exponential has no finite feature map (Sec 10.3).

One matrix, two algorithms, and the mix

Because M has this structure, there are two ways to apply it. The quadratic way builds M, as attention does, and multiplies: work grows with T^2, but all of it is matrix multiplication, which GPUs run on dedicated matrix-multiply units called tensor cores. The recurrent way carries the state forward: work grows with T, but in T sequential steps of small vector updates that leave the tensor cores idle. That was Mamba's position, a scan that is linear in length but "does not leverage matrix multiplication units" (Sec 2.1).

The SSD algorithm (Sec 6) cuts M into chunks of Q tokens. Each diagonal block is a small attention problem: compute it the quadratic way, all chunks in parallel. Every block below the diagonal has rank at most N, because M is N-semiseparable (Definition 3.1): each such block factors through an N-dimensional bottleneck, and that bottleneck is the state. Those blocks take three batched matrix products: each chunk's final state from its own inputs, a short scan that hands the state from chunk to chunk (T/Q steps instead of T), and each chunk's outputs from the state that entered it.

Before you press Chunks of 1: which entries will still be computed the quadratic way? Only the diagonal. With chunks of one token every other entry goes through the state, so the chunked algorithm with Q = 1 is the recurrence, and with a single chunk of length T it is attention. Q slides between the two. Now pick chunks of 4 or 8 and switch back to softmax attention. The same blocks turn red: their rank equals their size, so no small state can stand in for them. Chunking works for linear attention and SSD because of the low rank, not because of the block shapes.

With N = P = Q every piece is a batch of N \times N matrix multiplications, and the total work is O(TN^2) (Theorem 6.1). At T = 4096 and N = P = Q = 64, our count from the Sec 6.3 cost list gives 2.1 billion multiply-adds per head for the quadratic way, 67 million for the chunked one (99.6% of it in matrix products) and 50 million for the recurrence. Against attention, the paper's Sec 6.3 table puts training work at T^2 N for attention and TN^2 for SSD, the work per generated token at TN against N^2, and the state at T entries against N.

Does the saving show on a GPU? Measured on an A100 80GB PCIe with state size 64, the SSD layer runs 2-8x faster than Mamba's fused scan, and faster than FlashAttention-2 (a fast exact attention kernel) from sequence length 2K on, 6x faster at 16K (Fig 10 and Sec 1). Because the work is in matrix products, the state can also grow: the paper allows states 8x Mamba's size with little slowdown. Mamba-2 uses N "around 64 or 128" (Sec 7.2), where Mamba's experiments used 16; N=256 appears only in the recall test below and in ablations. One caveat from the paper: a whole Mamba-2 model may still train slower than a Transformer at length 2K, because half of a Transformer's layers are MLP (multilayer perceptron) layers, which are pure matrix multiplication (Sec 9.3).

Inside a Mamba-2 block: forward, then backward

The Mamba-2 block keeps Mamba's outline: widen, a short convolution, the SSM, a gate, narrow again. It changes how the SSM's inputs are made and adds one normalization. Step through it; the shapes are computed from the paper's configurations.

Claim: a bigger state recalls more, and with a large enough state Mamba-2 beats attention on a hard recall test at small model width

Source

How measured
Multi-query associative recall (MQAR): the model reads many key-value pairs, then must produce the value whenever a key appears again. Mamba-2 makes the usual version harder: a quarter as many pairs as tokens, sequences up to 1024 long, a vocabulary of 8192, filler tokens replaced by random ones. Every model has 2 layers; the model width is swept from 32 to 256. Baselines: softmax attention (with positional embeddings), Based, and Mamba with N=16. About 270M training examples.
Result
Mamba fails almost everywhere. Mamba-2 does better even at the same N = 16, and going from N = 16 to N=64 to N=256 consistently improves accuracy. In the hardest panel (length 1024, width 32), Mamba-2 with N = 256 answers roughly half the queries correctly while attention answers almost none (read from the plot, so approximate).

The paper is "not sure which aspect of the architecture is the predominant factor" in the gain over Mamba at equal state size (Sec 9.1). The win is at small widths: at width 256, attention solves the task too. Chapter 11, Where SSMs still lose, takes this up: a fixed state loses once what must be recalled outgrows it.
