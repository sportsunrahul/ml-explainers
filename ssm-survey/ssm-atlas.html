The bill attention sends

A cache that grows, against a memory that does not

To write the next word, a Transformer compares it with every word before it. To make that fast it keeps a : a key and a value for every past , in every layer. Each new token adds a column, so the cache (brown) grows for as long as the text does.

A keeps a instead (yellow): a fixed set of numbers that each new token updates. It never gets bigger. It only changes.

Linear recurrences

Why RNNs were dropped, and the change that brings them back

Presets
Cell

A (RNN) keeps a and updates it once per . Every token costs the same, at any length, and nothing grows. It is the cheapest memory a sequence model can have.

Strip it to one cell: ht = λ ht-1 + b xt. Each step multiplies what the cell holds by λ, then adds the new token. So a token that arrived k steps ago has been multiplied by λ k times. The chart is that : with |λ| below 1 the token fades, above 1 it grows without limit.

λ is an of the recurrence, and it can be a r eiθ. Then the cell also turns by θ each step, and its real part rings (try Ringing). With r = 0.9, only 0.52% of a token is left after 50 steps.

Press Nonlinear tanh RNN. Classic RNNs pass each update through a squashing function. Then no token has a fixed weight in the state, and step t cannot start before step t-1 is done: a sequence of length L takes L steps, one after another, even in training.

The repeated multiplication also hits training. The gradient back to an old token is multiplied at every step, so it shrinks or explodes: the problem. Press Exploding while in tanh mode: the state stays bounded, yet the red gradient line dies within 17 steps.

Press Linear. Without tanh, the recurrence unrolls into a weighted sum, ht = Σ λt-k b xk, and the bars are its weights. They depend only on how long ago a token came, so they are known in advance, and every state can be computed at once with a . That is what Transformers offered: every position trains in parallel.

LRU (2023) started from a plain deep RNN and changed one thing at a time: make it linear; make it diagonal and complex, so each cell updates on its own; write λ so that |λ| stays below 1 whatever training does; start the cells near |λ| = 1 for long memory; and normalize.

Why normalize? Near |λ| = 1 a cell adds up many tokens at almost full weight. Under random input its variance grows by 1/(1-|λ|²), the red bar: 5.3 at r = 0.9, about 500 at r = 0.999. LRU scales each cell's input by √(1-|λ|²) to cancel it.

A linear recurrence keeps the RNN's fixed memory and drops its two faults: its weights are known in advance, so training runs in parallel, and |λ| can be placed exactly where memory needs it.

HiPPO: memory as compression

Keep the best polynomial fit of everything seen so far

What should a fixed-size hold? HiPPO's answer is : at every moment, fit the whole input history with a polynomial of degree below N, written in , and keep its N coefficients.

The surface shows those coefficients over time: one row per degree n, height = value. The yellow line is the state now. As the history grows, the fit changes smoothly, and the change turns out to be a fixed linear equation with a specific matrix A. Raise N: the old rows do not move, new ones appear behind them, because A is lower triangular.

The state is only useful if the past can be read back. Sum the Legendre polynomials weighted by the N coefficients and you get the yellow line, drawn over the true history in blue; red is the error.

With N = 4 only the slow trend survives. With N = 16 the two slow waves come back. With N = 64 even the fast wiggle does. A KV cache would keep all 1,000 samples; this state keeps N numbers.

Mamba: input-dependent selection

Each token sets its own step size

Important tokens:

In S4 the step size Δ and the matrices B and C are the same for every token, so the model cannot tell a key word from filler. Mamba makes them depend on the token. This is : each token computes its own .

Mark a token important and it gets a large Δ: the yellow state flows toward it, forgets most of what it held, and stores the new value. Filler gets a tiny Δ, and the state barely moves. The green output keeps the last important value across the filler. The dashed path uses one Δ for every token and wanders with each of them.

With one state number this is exactly a : h_t = (1 - g_t) h_(t-1) + g_t x_t, with g_t computed from the token (Mamba's Theorem 1). Press All important: the state copies every token and remembers none. Selection only helps when it is selective.

A toy, computed exactly: one channel, three state numbers, A = diag(-1, -2, -3) (Mamba's default real initialization), Δ = softplus of a linear function of the important flag (2.13 or 0.049), zero-order hold per token. B is selective too; C is fixed. In the paper's ablations at about 350M parameters, a bigger state helps only when B and C are selective: perplexity 9.73 to 8.71 as N goes from 1 to 16, against 9.88 to 9.81 with constant B and C (Table 10).

A large step resets the memory and stores the token; a small step keeps the memory and skips it. Mamba lets each token choose.

The parallel scan

All the states of a recurrence, in a few rounds instead of one per token

Tokens
Step

Selection makes the recurrence change at every token, so the convolution trick of S4 is gone. A plain loop computes the states one after another: L tokens, L steps in a row. But every step is still "keep a of the old state, add b", and two such steps merge into one: (a1, b1) then (a2, b2) is (a1 a2, a2 b1 + b2). That merge is an , so the states can be computed as a , on a tree.

Going up, neighbours merge in parallel until the root holds the whole sequence. Going down, each node receives the state just before its span (yellow). One last merge per token gives every state. For 16 tokens: 9 rounds instead of 16, for about three times the arithmetic. At 2,048 tokens: 23 rounds instead of 2,048.

Kernel
Stage

Each token's state has D x N numbers, N = 16 times more than the layer's input and output. Writing all of it to the GPU's main memory and reading it back would cost more than computing it, because moving bytes, not arithmetic, is the bottleneck (see ).

Where SSMs lose, and hybrids

A fixed memory runs out of room; a little attention buys it back

Keys

Store K key-value pairs in a of N x N numbers by adding each pair on top of the others, the way linear attention does. Then ask for each key's value. This is , and the cache of attention (brown) gets every answer right.

The state (yellow) does well while K is small. Past K = N the keys can no longer stay out of each other's way, and the answers fill with crosstalk. Real models fail the same way on a or a : in NVIDIA's 8B study, pure Mamba models began to give wrong numbers past about 500 tokens of phone book. A big enough state wins, though: Mamba-2 with a state of 256 beat attention on recall at small model width. is a separate limit.

Preset
Context

A keeps most layers as Mamba and a few as attention. Only attention layers keep a cache, so the cache shrinks with every one removed, while the attention left over handles the exact lookups.

Jamba keeps 1 attention layer in 8, with a on every other layer: its cache at 256K tokens is 4GB against 32GB for Mixtral. NVIDIA's 8B hybrid (4 attention layers of 56) beat a Transformer trained on the same data on all 12 standard tasks and solved the phone book past 150K tokens.

A fixed-size state is lossy compression: it loses exact facts once they outnumber its room. A few attention layers bring them back for a small part of attention's memory.

KV cache

In attention, each token is turned into a query, a key and a value. A new token's query is compared with the keys of all earlier tokens, and the result weights their values. Earlier tokens never change, so their keys and values are stored instead of recomputed: that store is the KV cache.

Its size is 2 (keys and values) x layers x key-value heads x head dimension x tokens x bytes per value. It grows by the same amount for every token, and every new token must read all of it.

Token

The unit a language model reads and writes: a word, part of a word, or a punctuation mark. A sequence of length L has L tokens. In this tour "context length" means how many tokens the model has seen so far.

State-space model (SSM)

A sequence model that carries a hidden state h from one token to the next: h_t = A h_(t-1) + B x_t, y_t = C h_t, with matrices A, B and C. The idea comes from control theory, where the same equations describe physical systems in continuous time. S4 (2021) made it work for deep learning; Mamba (2023) made B, C and the step size depend on the input; A stays a learned parameter.

State

The fixed-size vector (or matrix) a recurrent model carries forward. Everything the model will later know about the past must be folded into it. Its size is set by the architecture, not by the length of the input, which is why the cost per token stays constant, and why the state is a lossy summary.

Recurrent neural network (RNN)

A network that reads a sequence one element at a time and carries a hidden state forward: h_t = f(h_(t-1), x_t). The same weights are used at every step. Classic RNNs use a squashing function such as tanh inside f; gated versions such as the LSTM (1997) and the GRU (2014) add learned gates that decide how much of the state to keep.

Generation is cheap, because each new token only updates the state. Training is slow, because step t needs step t-1 first.

Eigenvalue

A number λ for which a matrix A acts on some direction v as plain scaling: A v = λ v. Applying A k times scales that direction by λk. Most square matrices can be written A = P Λ P-1, with the eigenvalues on the diagonal of Λ; in that basis a recurrence h_t = A h_(t-1) + B x_t splits into independent cells, one per eigenvalue.

For a matrix that is not symmetric, the eigenvalues are in general complex numbers. LRU learns them directly.

Complex number

A number with two parts, written r eiθ: a size r and an angle θ. Multiplying by it scales by r and rotates by θ. Multiplying k times scales by rk and rotates by kθ, so a cell with a complex λ can hold a slowly fading oscillation. A model reads out the real part. LRU notes that the same thing can be done with pairs of real numbers, as the tanh toy on this stage does.

Impulse response

What a system does after a single input of size 1 followed by nothing. For the cell h_t = λ h_(t-1) + b x_t it is b λk after k steps. For a linear system it tells you everything: the response to any input is a sum of shifted, scaled copies of it. Read backward, it is the weight each past token has in the state now.

Vanishing and exploding gradients

Training sends an error signal (the gradient) backward through every step of the recurrence. Each step multiplies it by roughly the same factor, so over many steps it shrinks toward zero or grows without bound, and the model cannot learn links between distant tokens. The problem was studied by Hochreiter (1991), Bengio, Simard and Frasconi (1994), and Pascanu, Mikolov and Bengio (2013).

Parallel scan

A way to compute all the running results of a sequence, h_1, h_2, ..., h_L, in about log L rounds instead of L, by combining neighbors in a tree. It works for any associative combine step. A linear recurrence has one: two steps "multiply by a1, add b1" then "multiply by a2, add b2" make one step "multiply by a1 a2, add a2 b1 + b2". A tanh recurrence has none, so it cannot be scanned. Martin and Cundy (ICLR 2018) applied it to linear RNNs.

Long Range Arena (LRA)

A benchmark of six classification tasks on long sequences, from 1K to 16K elements: ListOps (nested math expressions), Text (byte-level movie reviews), Retrieval (do two documents match), Image (sequential CIFAR, one pixel at a time), Pathfinder and PathX (are two dots joined by a path, on 32 x 32 and 128 x 128 images). PathX was long out of reach for every model; S4 was the first to beat chance on it.

ODE (ordinary differential equation)

An equation for how fast something changes, instead of what it is. The state-space model says h'(t) = A h(t) + B x(t): the rate of change of the state h is A times the state plus B times the input. Solve it and you get the whole path h(t) through time.

Discretization

Turning a rule in continuous time into a rule for steps. Pick a step size Δ, solve the ODE over one step, and you get h_t = Abar h_(t-1) + Bbar x_t, a recurrence a computer can run one token at a time. Different methods (zero-order hold, bilinear, Euler) give slightly different Abar and Bbar.

Zero-order hold

The discretization Mamba uses. It assumes the input stays constant for the length of each step, and then solves the ODE exactly: Abar = exp(ΔA) and Bbar = A^-1 (exp(ΔA) - I) B. When the input really is constant between samples, the recurrence lands exactly on the continuous path.

Step size Δ

How much continuous time one token stands for. A large Δ lets each token push the state a long way and makes the old state fade quickly. A small Δ barely moves the state and keeps it for many tokens. LSSL notes that the length of the dependencies such a layer captures is roughly proportional to 1/Δ. S4 learns one Δ per channel; Mamba computes a new one for every token.

Legendre polynomial

A family of polynomials P_0, P_1, P_2, ... on the interval from -1 to 1: P_0 = 1, P_1 = x, P_2 = (3x² - 1)/2, and so on. Any two different ones are orthogonal: the integral of their product is zero. That makes them a clean basis: the best fit of degree below N is found one coefficient at a time, and adding a degree never changes the coefficients you already have.

HiPPO-LegS stretches them over the history [0, t] and scales P_n by the square root of 2n + 1 so that each has unit size.

Online function approximation

Approximating a signal while it is still arriving. At each moment you have seen the signal up to now, and you must keep a fixed-size summary that lets you rebuild it as well as possible. "Online" means you update the summary from the new value only, without going back over the past.

HiPPO's summary is the N coefficients of the best polynomial fit, and it shows that updating them is a linear equation.

Convolution kernel

A list of weights K_0, K_1, K_2, ... applied to a sequence by sliding: each output is K_0 times the current input, plus K_1 times the input one step back, plus K_2 times the input two steps back, and so on. A time-invariant SSM is exactly such a convolution, with K_j = C Ā^j B̄; its kernel is as long as the sequence.

FFT (fast Fourier transform)

An algorithm that turns a sequence of length L into its frequencies in about L log L steps instead of L². A convolution becomes a simple product in frequency space, so a long convolution costs three FFTs and one multiplication, not L² multiply-adds.

Low rank

A matrix of rank r can be written as a sum of r outer products, each a column vector times a row vector. A rank-1 matrix is one such product, P Q^T, and stores only 2N numbers instead of N². S4 writes HiPPO's A as a matrix that a stable change of basis makes diagonal, plus a rank-1 correction, and handles the correction with the Woodbury formula.

Selection

Mamba's change to S4: Δ, B and C are computed from the current token by small linear maps (with a softplus for Δ), instead of being fixed parameters. The model can then decide, token by token, what to write into its state and what to skip. The cost is that the long convolution of S4 no longer exists, so the recurrence must be computed with a scan.

Gate

A number between 0 and 1, computed from the input, that mixes old and new: h_t = (1 - g) h_(t-1) + g x_t. LSTMs and GRUs are built from gates. Mamba's Theorem 1 shows that a one-number selective SSM with A = -1 and a softplus step is exactly such a gate, with g = 1 - exp(-Δ).

Associative operator

An operation where grouping does not matter: (p o q) o r = p o (q o r). Addition and multiplication are associative. So is merging two steps of a linear recurrence, (a1, b1) o (a2, b2) = (a1 a2, a2 b1 + b2). Order still matters (it is not commutative), but because grouping does not, the merges can be arranged as a shallow tree and run in parallel.

Prefix sum, or scan

Given a list x1, x2, ..., xL, a prefix sum returns every running total: x1, x1+x2, x1+x2+x3, and so on. A scan does the same with any associative operator in place of +. A loop needs L steps in a row; a parallel scan (Blelloch's up-sweep and down-sweep) needs about 2 log2 L rounds, at about three times the work. The states of a linear recurrence are exactly a scan of its step pairs.

SRAM vs HBM

A GPU has two kinds of memory. HBM (high-bandwidth memory) is the large main memory, tens of gigabytes, where tensors normally live; reaching it is slow compared with arithmetic. SRAM is a small, fast memory on the chip, next to the compute units. Most operations other than matrix multiplication spend their time waiting for HBM, so a fast kernel keeps its working data in SRAM and touches HBM as little as possible.

Kernel fusion

A GPU kernel is one program launched on the GPU. Running several steps as separate kernels means each one writes its result to HBM and the next reads it back. Fusing them into one kernel keeps the intermediate results in SRAM. Mamba fuses discretization, the scan and the multiplication by C, so its large (B, L, D, N) state never reaches HBM.

Recomputation

Training needs the forward pass's intermediate values again in the backward pass. Instead of storing them, a model can recompute them when needed. Mamba does not save its (B, L, D, N) states: the backward kernel reloads the small inputs and recomputes the states in SRAM, which is faster than reading stored states back from HBM, and saves the memory.

Induction head

A pattern a model needs for in-context copying: having seen "Harry Potter" once, predict "Potter" the next time "Harry" appears. Attention does it by matching the current token's query with an earlier key. A time-invariant SSM cannot look up by content and fails the synthetic version of the task; Mamba's selective SSM solves it and extrapolates to sequences 4000 times longer than it was trained on.

Linear attention

Attention with the softmax removed. Softmax attention weighs past token s for query t by exp(qt · ks), normalized over the row. Linear attention (Katharopoulos et al., 2020) uses φ(qt) · φ(ks) instead, for a fixed feature map φ. Then the sum over the past can be kept as a running matrix S = Σ φ(ks) vsᵀ, so each new token costs the same and no KV cache is needed: the layer becomes a recurrent network.

Feature map

A fixed function φ applied to each query and key vector before their dot product. Linear attention uses φ(x) = elu(x) + 1, which is always positive, so every similarity is positive, as with exp. Mamba-2 applies SiLU to its B and C. Softmax's exp would need a feature map with infinitely many features, which is why SSD cannot express softmax attention.

Associativity

A product of three matrices can be grouped either way: (A B) C = A (B C). In attention, (φ(Q) φ(K)ᵀ) V first builds a T × T score matrix, which costs work growing with T². φ(Q) (φ(K)ᵀ V) first builds a small matrix the size of the features by the values, so the work grows only with T. Same answer, different cost.

Semiseparable matrix

A lower-triangular matrix is N-semiseparable if every block on or below its diagonal has rank at most N (Mamba-2 Definition 3.1). Every SSM with state size N is multiplication by such a matrix. Low rank means each block factors through N numbers, and those N numbers are the state. Mamba-2 also proves the converse: masked attention with a fast recurrent form must have a semiseparable mask.

Chunk

A run of Q consecutive tokens. The SSD algorithm splits the sequence into chunks. Inside each chunk it computes outputs like attention, all chunks at once. Across chunks it passes only the state: each chunk's final state, a short recurrence over chunks, and each chunk's outputs from the state that entered it. Q = 1 is the plain recurrence; one chunk of the whole sequence is plain attention. The reference code uses chunks of 64.

Tensor core

A unit on modern GPUs that does only one thing, small matrix multiplications, and does it much faster than the general-purpose cores. Attention runs almost entirely on them. Mamba's scan is a chain of small elementwise updates and cannot use them; Mamba-2's chunked algorithm turns almost all of its work into matrix products so that it can.

Patch

A small square of the image, typically 16 by 16 pixels, treated as one token. Its pixel values (16 x 16 x 3 colours = 768 numbers) are flattened and multiplied by a learned matrix to give a vector. A 224-pixel image gives 14 x 14 = 196 patches; the count grows with the square of the image size.

Class token

An extra learned token added to the sequence of patches. It carries no pixels; through the layers it collects information from the patches, and the classifier reads only its final output. In a Transformer its position does not matter. In a scan it does, because the scan only carries information forward: Vim found the middle of the sequence works best.

Vision Transformer (ViT)

A Transformer applied to images (2020): the image is cut into patches, each patch becomes a token, position embeddings record where each patch was, and standard attention layers process the sequence. DeiT is a ViT trained with a stronger recipe on ImageNet alone. Attention's cost grows with the square of the number of patches.

Raster scan

Reading a grid row by row, left to right, the way text is read (and the way a television once drew its picture). It turns a 2D grid into a 1D sequence, but it breaks neighbourhoods: the patch below is a whole row of steps away, while the end of one row sits right next to the start of the next.

Receptive field

The set of input pixels that can affect one output. The effective receptive field (ERF) measures how strongly each input pixel actually affects it, usually from gradients, and is drawn as a heat map. The figure on this stage is a toy version for one layer. A global receptive field means every pixel can matter, not that every pixel matters equally.

Detection and segmentation

Classification gives one label per image. Detection finds every object and draws a box around it (COCO is the standard benchmark, scored by box AP). Segmentation labels every pixel (ADE20K is a standard benchmark, scored by mIoU, mean intersection over union). Both use larger images than classification, so they produce thousands of patches instead of hundreds.

Associative recall, MQAR

A test of looking things up in the context. The model sees pairs such as "A 4 B 3 C 6", then a key such as "B", and must answer with its value, "3". Multi-query associative recall (MQAR), from the Zoology paper, puts many pairs and many queries in one sequence, which is closer to real text than one query at the end.

Phone book task

The prompt lists names with phone numbers, then asks for one person's number. The model must copy the right number exactly. A Transformer can look back at the line; a model with a fixed state must have kept it. Repeat After Me and NVIDIA's 8B study both use it.

Copying task

The model reads a string of random tokens and must then write it out again, token for token. Copying L tokens from an alphabet of D needs about L log2 D bits of memory, so a fixed state must fail once strings get long enough (Repeat After Me, Corollary 2.8).

Hybrid model

A stack that mixes layer types: mostly state-space (Mamba) layers, which keep a fixed state, and a few attention layers, which keep a KV cache. Jamba, Nemotron-H and NVIDIA's Mamba-2-Hybrid use global attention; Griffin uses local attention over a window of 1024 tokens.

Mixture of experts (MoE)

A layer with several expert MLPs and a small router. For each token the router picks a few experts (Jamba: 2 of 16) and only those run. The model can store many parameters but use only some of them for each token: Jamba stores 52B and uses 12B.

State tracking

Following a quantity that changes step by step, such as the order of objects after a series of swaps. Illusion of State shows that S4 and Mamba, like Transformers, cannot do this exactly for every length at a fixed depth, assuming a widely believed complexity conjecture (TC0 is not NC1) and log-precision arithmetic. It is a different limit from recall.
